发电机仪式 1~5 级结构 —— 会话交接笔记（2026-09-05）
=============================================================

【任务背景】
按用户提供的"五级多方块召唤祭坛"概念图，将其改编为【发电机仪式】的 1~5 级多方块结构。
要求：石砖→对应品阶仪式石（仅附加结构）；第 N 级新增环状结构的仪式石必须 N 级以上；
继承自低级层的格位仍允许低品阶。拟造装饰方块暂用原版方块替代（后续会实现专属装饰方块）。

三、环境坑（重要！）
1. run/mods 里的 forgematica-0.4.2 / mafglib-0.4.3 是客户端 mod：
   其 mixin（LevelChunk.redirectIsRemote 引用 LocalPlayer）在 dedicated server 上，
   一旦世界 tick 走到 setBlockState 该路径（如树叶计划刻衰减）就 FATAL 崩溃
   （崩溃报告：run/crash-reports/crash-2026-09-05_14.54.46-server.txt）。
   临时方案已内置于 tools/_run_ritual_test.ps1：跑服前把两个 jar 挪到 tools/_mod_stash，finally 恢复。
   长期方案待用户决策（如标记 client-only / 移到其他目录 / forge 端禁用）。
2. 测试服务器进程可能残留：先 `netstat -ano | findstr 25565` 再 Stop-Process（上次已手动清理 PID 5772）。
3. run/ 为 runClient/runServer 共用目录；gs_ritual_test 数据包的 load 标签【每次世界加载都会自动
   setblock 四个测试结构（y=100 天空）】——验证通过后务必删除该数据包。
4. gradle 长命令按项目约定重定向到文件再读：cmd /c "gradlew.bat runServer --console=plain < run\stdin.txt > build_out.txt 2>&1"
