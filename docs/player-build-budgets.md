# 玩家构筑数值基线

本轮数值源为`balance/BuildNumbers.java`，符卡参数清单为`balance/SpellParameterPolicies.java`；不是TOML战力配置。原`BalanceNumbers.GRACE_DEFAULT_ROWS`保留池/强度和旧数据参照，新成长的生命、护壁、暴击及符卡属性由`GraceNumbers`调用新表抽取。

## 阶级与属性

- 自身标准HP：28/36/44/52/60；每阶仅增加约7.6～8，五阶58～60，避免大量血条。外部模组生命不清除。
- 标准直接EHP：56×10^(阶-1)，P由`log2(EHP/HP)`反算。各阶先天P窄波动，全身P跨度最多log2(3)。普通敌弹基线约2～8次无回血直接命中；实际BOSS仍保留各自旧bossHits比例及程序damageScale，不把所有弹型当同一伤害。
- 综合阶差看标准属性合计，不要求基础强度或各流派都精确十倍。
- 流派属性以逐阶差值、u³偏低分布抽取，低值常见、高值稀有；生命、池、强度与回灵使用自身受控带。杂项保留有限范围。
- 同属性来源平加，最终边界在读取时处理，原始贡献保留。`/gs_attributes show`显示raw/min/cap/生效与限制标记。装备不写池台账。
- 额外灵力强度上限为该阶基础最小值3%，以具体数值显示。

## 资源与攻速

费用依据固定阶级标准，不随玩家实际池提高涨价。武器按完整每触发payload归一（激光含全部脉冲）；基础费用还考虑阶级目标战斗窗口。回灵基准池0.12%/s，汲取额度池0.03%/s，仅主武器触发。

`SpiritPayments`为武器/已学卡共享小数支付通道，余数持久化且死亡保留，防止高阶float池吞掉小额支付。余额不足不发射/施法。旧全甲+50%回灵本轮兼容保留，需无甲/全甲分别验收；星银未接入旧强度收益不顺手启用。

攻速为频率加成。长按使用服务端逐tick累计，可在一个tick产生多个合法发射；idle不储存burst。旧核缺版本时按旧间隔缩短语义转换读取，新核版本1表示频率语义。第二change才实施新版核生成与词条版本写入；本轮不自动补条、重掷或写回旧核。

## 符卡清单与限制

新属性：spell_damage_amp（符卡强度）、spell_heal_amp（治疗）、spell_duration、spell_cost_reduction；CDR复用原键。旧spell_amp保留单一legacy贡献，仅旧治疗/召唤消费者继续读取，不复制来源；与分类增幅平加后各自封顶。

- 无想封印：damageCap吃强度，持续吃时长，6玉/脉冲机制固定；基数按固定D0生命周期预算适配。
- 冰符：单发伤害吃强度，弹数/散射/寿命固定。
- 狐召唤：攻击值吃强度，生命周期吃时长，数量/追敌机制不改；按固定D0预算分摊每秒伤害，不按实际武器DPS动态增强。
- 花园：每秒治疗吃治疗强度，时长可延长，同目标同tick只取最强同类场（含不同玩家）；普通基础总量约标准HP25%，最短冷却60s。
- 花瓣：基础1次，强度后最多2次，20s寿命可延长，重施替换不累加；最短冷却120s。
- 黑暗/蛛网/疫符：特殊参数固定，不自动吃通用强度或持续；费用/CDR仍经统一消费。光反仍为空实现，不用它证明流派可用。

可选最终参数上下限、最短冷却默认不启用，启用后任何增幅不能突破；限制在指导书说明。道具卡按固定品质基准，不读玩家构筑属性。

## 兼容与验收边界

登录不再按旧量级随机重掷，已有台账原样保留；缺台账按固定权重重建份额，池总量、当前池与buffer保留。版本标记独立，不覆盖旧贡献。旧超范围属性仅钳生效值，旧核组合预算例外不谎称满足新版生成规则。

模型报告位于`build/reports/build-budget/`，生成器及测试在`src/test/.../balance/`。动态TTK使用成功支付才生成的后续脉冲，生存模型独立区分无恢复、治疗、盾和有限补给。模型忽略追敌延迟等世界因素，不能替代客户端生存实测。

**尚未完成**：第二change新版核实际生成与联合验收、一/三/五阶客户端生存实测、真实多人治疗场去重与持续召唤性能。不得仅凭构建成功宣称这些已通过。

后续事项：盔甲套装改为不影响核心战斗属性的其他功效；本轮不指定替代效果。早期固定卡、幻想乡学卡、无限学习及自由配装由后续符卡变更处理。
