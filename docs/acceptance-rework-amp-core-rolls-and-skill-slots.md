# 验收步骤：rework-amp-core-rolls-and-skill-slots

> 覆盖：增幅核新版生成（统一池 3/4/5 条）、星移洗练共享池、旧核/跨版本预览迁移、技能槽 1~5。
> 前一 change 的验收仍以 `docs/acceptance-rework-player-stat-build-budgets.md` 为准；本文是补充。
> **所有命令都需要 `permission 2`（作为 OP）。建议用独立存档。**
> 每测一项**先记录再改设置**；任何一项对不上，绝不要先调数值——把现象记下来再问。
> `/gs_test player N` 每次都会发一把新的千机核心（武器+三个核），背包满了旧的会掉地上——注意。

## 1. 新版首次生成分布（抽样 50 枚 × 三个阶位）

```
/gs_test reset
/gs_test player 5          # 五阶，便于一次性收集大量 T3 核
```
- 创造模式取出 T1/T2/T3 增幅核（取出瞬间即 roll 第一次），装入武器槽观察 tooltip；或直接用星移仪式看预览取样。没有直接的 /give 指令，这是正常路径。
- 记录每个核的词条（对着核截图/观察 tooltip）：
  | 抽查项 | 通过标准 |
  |---|---|
  | 条数 | T1=3 / T2=4 / T3=5，**同一核不出现重复 id** |
  | 类型 | 同时存在武器域（damage_pct 等）与玩家属性域（crit_chance、spell_cdr 等） |
  | 高值 | 多数核偏低值（扫一眼即可）；偶见 ≥90% 单项带上限 |
  | Melee/Jump 杂项 | 正常出现，数值不离谱（jump ≤ +25%） |
- **注**：分布精确统计请以自动化报表为准（`build/reports/build-budget/core-generation.md`，需重跑对应测试生成），本节只做肉眼抽查。

## 2. 星移洗练（T3 = 5 条，共享池）

需要能洗练 T3 核的五阶星移核心（见仪式档）。
```
/gs_test player 5
```
1. 把一枚 T3 增幅核放进仪式核心「增幅核槽」，完成一次洗练。
2. 预览面板：**Tx 阶核，5 条词条**（不是 T1 的 3 条，也不是 1 条）。
3. 逐条确认词条 id 无重复、域混合（武器 + 属性/护壁 均可出现）。
4. 采纳后：新核在 tooltip 中显示 5 条新词条；旧档老核未受影响（见第 4 节）。
5. 预览中生效值/溢出提示（若某属性词条已到该阶上限）：行末附带 `(+x%)` 生效差值，列表末尾出现「部分词条已触及本阶属性上限」提示。
6. 保留原核后再洗：洗练度 +1（软保底），采纳后洗练度减半（隐藏机制，不可见；验证方式见自动化测试）。

| 检查 | 预期 |
|---|---|
| T3 洗练预览 | 5 条唯一词条 |
| 采纳/保留 | 整组采纳或全部保留；无「只取部分词条」 |
| 仪式经济 | 成本/催化剂/缓存/受灵速率**未改变**（与新条数一致） |

## 3. 技能槽（1/2/3/4/5）

```
/gs_test reset
/gs_test player 1          # 一阶：1 个技能槽
/gs_test player 0          # 凡人：0 个技能槽（HUD 不显示）
/gs_test player 5          # 五阶：5 个技能槽
```
| 检查 | 预期 |
|---|---|
| 零阶 | 无技能槽显示；施放被拒绝（提示需进阶） |
| 一阶 | 1 个槽；已学卡（若有）正常；空槽不自动授予 |
| 二阶 | 2 个槽 |
| 三阶 | 3 个槽 |
| 四阶 | 4 个槽 |
| 五阶 | 5 个槽；已学习的卡不丢失、冷却保留、槽位配装不变 |
| 换槽 | 卡从槽 A 换到槽 B 后，槽 B 的冷却不清零 |
| 旧角色 | 升级后既有冷却/配装不丢失；新槽保持空 |
| 旧学习上限 | 不随槽数放宽：一/二阶仍不可学习任何卡（旧上限 0）；三阶上限 1 张、四阶 2、五阶 3（不变） |

## 4. 旧核与跨版本兼容

用**升级前存档**进游戏：

| 检查 | 预期 |
|---|---|
| 旧增幅核装备 | 正常生效，词条原样保留；不自动补条或重掷 |
| 旧攻速词条 | 仍按旧语义（区间减少）结算，不突然变快 |
| 旧 spell_amp 值 | 只按 legacy 用途（治疗/召唤消费者）生效，与分类增幅平加后各自封顶 |
| 旧核采纳一次新规则洗练 | 核升级为新版（词条/攻速语义全部按新版结算） |
| 更新时带的待决洗练预览（有未决洗练时升级） | 可采纳则按 legacy 身份转换写回（词条保持旧语义，提示「已采纳旧版洗练结果」）；采纳瞬间预览若来自更新版本，明确作废并提示，原核不动 |
| 换维度/登出再进 | 老核状态幂等（无重掷、无补条） |
