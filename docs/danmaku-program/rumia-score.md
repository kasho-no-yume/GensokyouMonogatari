# 露米娅谱面 v3：空间约束与驱赶

替代v2正面锥形方案。正式内容与预览均来自RumiaPrograms，网页面板包含完整逐卡说明。
本版为待用户逐卡审阅的原创三维编排，不声称原作复刻或完成实机难度验收。

## 共同条件

- BOSS在16秒轮次内锁位，使战斗域始终以BOSS为中心。公共幕只生成一份。
- 每次点名重新捕获40格内最多5名玩家，各人单独锁定眼位；预警1.5秒，之后不追踪。
- 光条幕为47条84格长光束，间距1.7格，源端在局部z=-42，实际伤害半径0.4格。
  光条间弹体边缘净距0.9格，玩家身体中心可用宽度更小；允许主动穿缝，不能当宽阔走廊。
- 光幕预警2秒。幕和点名穿过地形：避免场地弹被地面截掉，也必须实测遮挡后的预警可读性。
- 旧幕按寿命跨轮保留，切卡清场。预览不模拟方块遮挡和真实玩家碰撞。

## 验收方式

RumiaCoverageTest在真实运行器中测试六方向8/32格站桩、24格绕圈和升降轨迹。
几何探针不处理无敌帧、玩家AABB、障碍物和实际操作，不等于实机通关证明。
本轮反馈尤其关注：绕圈是否仍能逃课、激光是否过度遮挡、过缝是否太窄、五卡是否过于相似。
规范和失败案例见[三维设计契约](3d-design-contract.md)。

固定绕圈探针使用半径24格、高度3格、角速度0.0125弧度/tick；
升降探针使用x=8、z=6、y=26·sin(0.0125·tick)。两者各运行32秒。
这是有限的反例筛查，尚未覆盖任意初始高度、速度及相位。

已验证：六方向8/32格站桩的60种卡位组合均受到个人驱赶；
五张卡的固定绕圈、升降探针均遇到公共幕；导出首轮出生时刻/数量与谱面匹配且无撤批。
其余15张卡的导出运动数据与原版一致。
最终 `build exportDanmakuPreview` 通过；单独串行多人测试通过，确认五人个人弹量
与公共幕量分别展开。未做浏览器画面与生存实机验收。
