# 现有符卡与操作映射

基线：2026-10-15 的 `sheet/bossspellcard.xlsx` 三页和当前 `BossCards.java`。前三只按表格意图迁移；露米娅/傩面按代码声明迁移。源文件不在本 proposal 阶段改写。所有数量均为未触发预算、安全或碰撞取消的名义出生数，不是存活峰值。

## 1. 共同策略

- Lane 仍承担视觉身份和伤害倍率；Group 可以跨 Lane。移动锁改为 owner 控制轨声明，与通用游走共同遵守锁释放。
- 同一符卡正常循环允许旧代继续，按各卡 tailPolicy；切换到不同符卡则旧卡归属立即停判伤和结束。大妖精与山女底噪归 encounter 独立实例，切卡不重置其频率；死亡时一起清理。
- 现有循环边界血量切换保持；一次掉血越过多个门槛可能跳卡，重构不自动变为八卡必演。
- 当前代码注释存在速度/寿命过时值和文字乱码，数值依据表格+实际构造参数核实。差异日志至少含 intended/legacyObserved/newObserved/reason。

补充实现细节：

- 卡2面板源中心在O平面±1，左右±4符印是次序标识；真正预警必须同时显示面板轮廓，不能拿±4点符印假称完整出生提示。
- 卡4射线两端断口使用真实起点Q±1.5R，半径.18，名义物理净宽2.64；不能用一整条激光视觉中间擦除来伪装无伤害缺口。激活时检查中心走廊方块净空与声明净宽，失败撤该激光批。
- 卡6弧线提示引用同一未来路径；整片只平移，不随切向旋转局部面。若添加OrientAlongPath会改变sheet设计，禁止默认开启。
- 卡6“相对F水平转向”明确取锁定帧U为转轴（F/R平面），保证末端回F；不要擅用世界Y导致倾斜帧下终点不一致。
- 卡8副轨必须复用各子轮主目标帧，而非到84/144才另采样。个人轨每目标帧与公共主目标帧分别有明确句柄。
- 表格共通行提到终符.70大玉，但卡8具体参数与构成为全部.40，无大玉成员。本次按卡8详细构成（.40）作为权威迁移值，登记表内冲突，后续同步表格说明。

## 6. 额外组合探针（必须，非新增正式符卡）

1. Rose随Arc整体推进，同时Rotate+Breathe；到指定时刻只让偶数瓣Detach径向，花心和奇数瓣继续；验证同通道组合、局部/整体分离、部分脱离。
2. 48成员同组跨48拍点亮，锁定group time；与单拍48成员在同一后续时刻重合，玩家横移不改变帧。
3. 激光节点在父组Orbit下旋转自身朝向，预警与光束同一姿态曲线，碰撞长度按服务端地形裁剪。
4. 双轨共享同一帧，删除其中一轨的成员不销毁共享帧；最后一个使用者结束才释放。
5. 远离owner的子组仍被兴趣管理追踪；客户端中途进入直接恢复当前状态，不补播爆散或声音。
