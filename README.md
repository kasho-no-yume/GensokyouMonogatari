# 幻想乡物语 · Gensokyou Monogatari

东方 Project 题材的 **科技魔法兼顾 RPG** 模组 —— Minecraft 1.21.1 / NeoForge。

## 技术信息

- **平台**：Minecraft 1.21.1 · NeoForge 21.1 · Java 21（Gradle + ModDevGradle 2.0）
- **依赖**：Patchouli（指导书框架，外部安装、不内嵌）、GeckoLib 为硬依赖；JEI 可选（仪式配方展示）
- **构建**：
  ```powershell
  gradlew build        # 打包 jar
  gradlew runClient    # 开发环境客户端
  gradlew test         # 纯 JVM 单元测试
  ```
- **代码组织**：Java 位于 `com.bitsson.gensokyou`，按域分包（`ritual` / `entity` / `item` / `spirit` / `network` / `client` …）；数据与资源在 `src/main/resources/{data,assets}/gensokyou`
- **开发约定**：需求基准 `openspec/project.md`；设计与数值规范 `docs/*.md`；数据生成/校验脚本 `tools/`；AI 开发手册 `.opencode/skills/`
- **许可证**：All Rights Reserved

## 幻想乡物语 · 玩家的话

> 你以为你熟悉的这个世界，只是幻想乡漏出来的一角。

东方 Project 与 Minecraft 的相遇。你依旧从一双手、一座草屋开始，但这个世界暗流涌动：田野间盘旋的小妖精正等着朝你倾泻弹幕，破碎的结界背后，沉睡着一整座只存在于传说中的乐园。这里没有开局送你的神装，只有一本沾着尘土的手册——和一个邀请：**想不想变强到超脱人类？**

### 第一课：从一只妖精开始

别小看那些在头顶绕圈的小妖精。它们掉落的 P 点与円，是你踏入这个世界的全部启动资金。等你攒够了仪式石与仪式核心，在草地上摆出第一座法阵，献上催化剂——轰，结界波动，**芙兰朵露·斯卡蕾特**降临。第一次被漫天弹幕追着跑的狼狈，会成为你记很久的回忆。打赢她，招牌武器莱瓦汀就是你的了。

### 弹幕，才是真正的战斗

这个世界里，普通刀剑砍妖怪只掉一层皮——**东方系的妖怪对非弹幕伤害减免九成**。想赢，就得学会用弹幕说话。把弹核、等级核、增幅核装进**弹幕方术装配台**，造一把属于自己的弹幕武器：单发球、穿透飞刀、散射、追踪灵符、激光枪炮，每种手感都不同，符文词缀还能把它们改造成你想要的样子。而当你面对 BOSS，别只会莽——**擦弹、灵力护壁、走位**，才是东方式战斗的正确打开方式。护壁的减伤是**指数级**的，练到家时，同阶弹幕打在你身上真的就像风一样。

### 符卡：把幻想装进卡里

「梦想封印」「冰击」……一张张符卡就是具现化的招式。掉落的符卡道具即拾即用、无需门槛，是你练度不够时提前体验爆发的手段；而真正强大的是**已学符卡**——装进技能槽，用灵力持续施放，成为你的战斗核心。技能槽有多少，取决于你把自己修行到了哪一阶。

### 修行：从凡人到超人类

凡人没有灵力、没有技能槽、甚至飞不起来。想要变强，你得走进**八百万神恩之仪**，献上稀有材料与海量灵力，请神明赐下一线恩泽。每一次进阶都会**永久**提升你的灵力上限、恢复速度与战斗素质——门槛一次比一次昂贵，回报也是一阶比一阶夸张的力量。修行路上还能**洗练**重掷属性，不满意就再来一次，直到你得到完美的那一身。

进阶之后，你终于可以**凭灵力飞行**——阶级越高，维持飞行的灵力开销越低，五阶的修行者甚至能让灵力的翅膀几乎不花代价地载着他掠过群山。那是一种原版生存永远给不了的自由。

### 仪式：用石阵驾驭灵力

灵力不只在身体里，也能被收集、储存、传输、转化。**仪式系统**是这个模组的科技侧心脏：以仪式核心为中枢、仪式石按图案围出法阵，你就能造出各式各样的设施——

- **日轮天台 / 月影水镜**：白昼与黑夜交替产灵，日出而盛、日落而息；
- **梦渡之座**：在仪式床上安眠，整夜的梦境化作灵力；
- **八方归元之仪 / 万象共鸣**：把散落各方的灵力汇入共享的池子，并在仪式之间远距离传输；
- **迦具土炎炉、源初造化之仪**：以火换灵、以原料造万物；
- **金山彦命煅炉、大山祇神之座、久久能智神庭、绵津见神之藏、草野姬神花亭、埴山姬神之壤**：以工具献祭，换来矿产、木材、海产、花草——幻想乡独有素材尽在其中，且产量随法阵阶级成倍暴涨，**前期涓涓细流，后期取之不竭**；
- **无尽藏晶**：把一整座仓库塞进一颗晶石，物品分门别类、取之不尽。

不熟悉法阵？**仪式构建器**会替你预览图案、清点材料，甚至一键把你手上的核心搭成完整结构。书上每个仪式都有 3D 投影，照着摆就行。

### 结界的背后

当你的力量足够，就能启动那场一次性的大仪式——**引爆结界**。轰的一声，天空裂开隙间，**幻想乡维度**永久向你敞开：迷雾竹林、雾之湖、魔法森林、守矢山、三途川……熟悉的风景，陌生的规则。这里住着愿意与你交易的居民、发布委托的 NPC，还有藏身**寝宫**深处的高阶 BOSS。习得已学符卡的唯一途径，就藏在幻想乡的委托任务里。

而幻想乡之外，还有更远的东西在等着你——**降神**：把神灵的部分力量封进容器，短暂地借用祂们的战斗方式，甚至替换你的一整套技能槽。今天你是修行者，明天你或许就是那尊神本身。

### 未完待续

《幻想乡物语》仍在持续生长。已经可以玩到的有：妖精生态、弹幕战斗与装配、道具符卡、炼体进阶与飞行、十余座功能各异的仪式、幻想乡维度与商人委托。接下来要做的，是更多神明、更多寝宫 BOSS、更多委托与剧情——那座只存在于传说中的乐园，正在一砖一瓦地被砌起来。

**欢迎来到幻想乡。这一次，故事由你亲手写。**
