# Proposal: 阶段 B — 灵力经济基建

> 需求依据：`openspec/project.md` §3.1/§3.2/§3.4、§7 阶段 B。
> 本提案为**框架级**：划定本阶段交付边界；design/specs/tasks 在开工前细化。

## Why

阶段 A 的战斗是"无资源"的（道具卡即拾即用）。阶段 B 建立灵力经济与炼体成长，
让玩家从"用道具"过渡到"养角色"，并产出后续大型仪式（结界引爆、降神）所需的全部基建件。

## What Changes

- **个人灵力池**：玩家自身产灵力（速率/上限受体质约束），HUD 灵力条；死亡清零当前值、永久属性保留
- **发电机仪式**：多方块结构，持续产出灵力
- **电容**：灵力储存容器；可向仪式供能，也可喂给玩家
- **传输仪式**：电容间/电容到设施的灵力传输（不做免费无线传输）
- **分解 / 聚合仪式**：功能性加工——矿物增产、材料处理、强力道具合成
- **淬炼仪式（炼体）**：消耗大量灵力 + 稀有道具，提升最大灵力/恢复速度等永久属性
- **更多道具符卡与召唤目标**：扩充符卡图鉴；第二个可召唤 BOSS（名册待定，见 project.md 开放问题）
- **无力（MuPower）效果**：补齐弹幕伤害倍率公式的另一半

## Capabilities（本阶段将产出的 spec）

- `spirit-power-pool`：个人灵力池与 HUD、死亡规则
- `power-generator-ritual`：发电多方块
- `spirit-capacitor`：储能容器与充放规则
- `power-transmission`：传输仪式
- `processing-rituals`：分解/聚合加工
- `tempering-ritual`：炼体成长曲线
- `spellcard-expansion-b`：第二批评测卡

## Impact

- 依赖阶段 A 的注册骨架与配置框架
- 多方块结构匹配系统在本阶段首次落地（A 阶段召唤仪式为其先导）
- 所有数值进配置文件；dedi server 安全为硬性要求

## Out of Scope

技能槽/HUD 键位释放（C）、幻想乡维度与商人（C）、委托任务（C）、降神变身（D）
