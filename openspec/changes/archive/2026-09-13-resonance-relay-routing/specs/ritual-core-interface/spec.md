# ritual-core-interface Delta Spec

## MODIFIED Requirements

### Requirement: 仪式自定义操作
行为 SHALL 可通过 uiActions 向界面注入自定义操作按钮（框架启停之外），点击经服务端 onUiAction 权威执行并刷新界面。同一服务端权威通道 SHALL 亦承载信息行内控件的点击回报（携带操作 id 的行，见 `ritual-gui-info-lines`），行为侧以 id 命名空间区分按钮与行操作，客户端 MUST NOT 直改服务端状态。

#### Scenario: 电容存取按钮
- **WHEN** 打开电容环界面并点击取出/存入按钮
- **THEN** 灵力按既有规则转移并在界面上看到数值刷新

#### Scenario: 行操作与按钮共用通道
- **WHEN** 玩家点击行为注入的可交互信息行
- **THEN** 服务端以 onUiAction 收到该行的操作 id，校验并回推快照，流程与按钮一致

### Requirement: 仪式信息展示
界面 SHALL 展示当前匹配的仪式名称、可达层级与运行状态（运行中/已停止），以及该核心的概要数据（如存储灵力）。对容量判定为 0 的仪式核心（无缓存型，如万象共鸣之仪），固定头 SHALL NOT 显示存储灵力数值行，概要数据由行为注入的信息行替代。界面布局 SHALL 为：固定头部（名称/层级/状态/灵力）+ 右侧功能栏（灵力核心槽、启停按钮、行为操作按钮）+ 中部行为自主信息显示区（见 `ritual-gui-info-lines`）+ 底部玩家物品栏；面板宽度 SHALL 加宽至 248px 以容纳分区。

#### Scenario: 信息核对
- **WHEN** 玩家打开运行中的发电机环界面
- **THEN** 显示发电机名称、层级、运行中状态与相关数值，功能栏与信息区互不遮挡

#### Scenario: 无缓存塔不显示灵力行
- **WHEN** 玩家打开成型共鸣塔的界面
- **THEN** 固定头无"灵力 0/0"行，改由信息行呈现链接数与吞吐摘要
