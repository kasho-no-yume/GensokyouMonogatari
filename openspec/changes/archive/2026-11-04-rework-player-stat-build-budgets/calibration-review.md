# 校准关卡审核摘要

状态：待审核。模型与候选值不等于实机通过，正式数值尚未替换。

## 已确认方向

- 五阶自身标准60HP、窄波幅；生命候选28/36/44/52/60，标准直接EHP约逐阶十倍，由护壁承载。
- 综合阶差看所有标准属性，不要求单属性或每条流派精确十倍。
- 无恢复直接耐弹约2～8次，治疗/挡弹收益另外报告，不限制原版回血。
- 单枚增幅核为当前构筑来源；核数量、生成与槽扩容由第二change实施。
- 旧天赋/物品不自动重掷，旧spell_amp保留legacy用途，新分类来源不复制旧条目。
- 输出/治疗基础数值允许适配；逐卡参数增幅清单，可选最终上下限/最短冷却，限制记指导书。
- 弹幕核核阶 T1/T2/T3 接管原武器等级倍率 [1,2,4]（等级核退为装配闸门）；匹配装总量、D0 与 BOSS 血量不变；低阶核在高阶武器仅吃自身核阶倍率（2026-11-03 定案，见 design D7）。

## 候选资源与卡片

- 自然回灵参照固定池0.12%/s；旧全甲兼容0.18%/s。球核费用=固定池×(1/参考战斗窗口+0.0006)/2.5；其他七核按完整每触发payload比例起算，需要多目标效益回归。
- 狐召唤基础生命周期总伤害=固定D0×0.4×20s，按原生命周期分摊每秒，20s基础冷却，费用固定池3%；不改召唤附身机制，不动态读取武器DPS。
- 治疗普通单次总量为标准HP25%，+50%治疗可提高，时长延长不提高每秒恢复；同目标同类场取最强，不多人叠加。基准冷却候选60s。
- 花瓣盾候选基数1，强度可提高但最终容量≤2，基础20s可延长，最终最短冷却120s。目的不是限制回血后累计承伤≤8，而是避免一张短CD卡抵消整场受击。
- 其他现有伤害卡按固定标准D0生命周期预算适配；控制/免疫不额外增强其特殊参数，必要最短冷却逐卡验证。光反保持未实现，不纳入有效卡组论证。

## 核候选预算

核阶T1/T2/T3参照玩家1/3/5阶，3/4/5条、类型权重候选均6。数值在各自零至最高带以u³抽样，整核评分上限1.5/2/2.5；评分=sum(归一数值²×权重)，攻速2、攻击/暴击0.7、其他1。

另用最坏天赋下的武器乘数≤2.5/4/6及持续吞吐因子≤4/8/16约束生成，避免单一评分漏掉乘法协同。64次有界重试后返回低值合法核，预算不要求花满，不保证每次有极品。

10万枚/核阶采样可出现单项高值及多条高值；这些是统计候选，不是新版实际生成器已实现。

## 验证范围与剩余关口

已有：固定种子分布、四乘区网格、五阶六流派同分值可行搜索、动态付费召唤/缺灵停火TTK、借高阶合法核、无恢复2～8次边界、恢复/盾寿命事件及资源耦合。

尚未证明：真实服务端发射/命中与召唤追敌利用率、全部卡组合连续上界、多人治疗去重实机、原版自然回血真实tick模拟、第二change实际生成器概率、新旧存档及客户端生存实测。核阶重做未实施：同武器换核梯度、低核高阶惩罚、tooltip 口径均无实机结论（tasks 第 6 节）。前者可在接入过程中回归，后者是最终验收任务，不提前勾选。

若审核接受此表作为实施起点，1.3/1.4可按“表已产出”完成，1.5/1.6仍需补全实际可达组合/跨阶结论与阈值后通过正式关卡。若不接受，保持候选隔离，不改正式战力常量。

## 2026-11-04 新版核生成实施（待审清单，供审核）

实施结果（详见 `../rework-amp-core-rolls-and-skill-slots/`）：统一受控池（22 种，首次/洗练同池，写死 ID 唯一）、T1/T2/T3 = **3/4/5 条**（BREAKING）、低位偏置抽样 q=u^k(t)（k=3→1，软保底只压平指数、不抬上沿）、**整核组合预算在生成阶段拒绝**（复用本文件口径：评分+最坏先天武器乘数 2.5/4/6+符卡吞吐 4/8/16；64 次有界拒绝 → 确定性低位合法回退，缩放向 0，条数不减、不补极品）、旧核不重掷/不补条（显式 legacy 例外）、新旧待决预览按规则版本隔离（legacy=身份转换保留旧语义；未知=明确作废保留原核）、技能槽 clamp(tier,0,5) 与旧学习上限（max(0,tier−2)）彻底解耦。

**数值全部为候选，未获准通过 1.6。** 与旧口径的差异（spec 与本次审计强制要求）：

1. **（规格变更，非可选）玩家属性词条改为绝对贡献带**。spec 明文：概率属性绝对百分点、MUST NOT 统一用 1~8% 小额比例；灵力强度绝对点数并受实际玩家阶总额度约束（仍由 finalValue 钳制）；护壁绝对指数（目标减伤 pct→ΔP）；其他/杂项按各自单位有限区间。**18 × 3 个绝对带数值全为新候选，需逐一审核**（见 `CoreAffixCatalog.ATTR_ABS_BAND`）。
2. **RUNE_ATTR_BAND config 语义从「pct-of-标准」改为绝对值**（旧配置行若有将改义；默认为空不受影响）。
3. **软保底机制改为「k 压平」**：k(t)=3−2t，t=1 时均匀；不再平移带宽/不抬上沿/不改类型权重（spec：洗练度 SHALL 只改善有界分布，MUST NOT 平移上沿）。旧 `pityBand` 已删除。
4. **攻速词条 = 频率加成**（×(1+r)），新生成核写 RUNE_VALUE_VERSION=1；旧核按 1/(1−r)−1 兼容读取。星移预览 DPS 粗估同步修正。
5. **回退语义**：64 次拒绝后回退值可低于带下沿（向 0 缩放），条数不减、确定性、合法；100k 样本回退率 0.00%。
6. **攻速词条高 roll 被预算拒绝殆尽**（攻速权重 2.0 + 带只 6/10/15% ⇒ 任何 ≥75% frac 的核必超 1.5/2.0 预算；10 万样本 T1/T2 高值出现率 0%、T3 0.1%）——**攻速权重 2.0 与窄带组合使高攻速投放实际不存在**。需裁定：降权重（如 1.0）、放宽带、或接受「攻速只出低中值」。
7. **首次/洗练同池后，首次不再只抽武器词条**（修复 T3 首次最多 4 条、洗练误用 T1 条数）；首次生成写 RUNE_VALUE_VERSION=1/CORE_RULE_VERSION=1。
8. `DANMAKU_REDUCE` 词条带 = 目标减伤 pct（T1 1~3%/T2 2~5%/T3 5~8%），换算绝对 ΔP；与既有护壁模型衔接 ✓。

11. 新增 `CoreAffixCatalog`（统一定义表 + 校验：唯一 id、带合法、权重为正、**每条登记真实消费路径** `consumerOf`，缺失即显式失败）。
