# weapon-gui-visual Delta Spec

## ADDED Requirements

### Requirement: 弹幕武器图标为弹幕铳造型
`danmaku_weapon` 物品图标 SHALL 重绘为可辨识的弹幕铳（枪形）造型：暖金机身 + 深紫描边，与弹核系列（core_*.png）同族配色，枪管/握把轮廓一眼可辨。

#### Scenario: 图标可辨识
- **WHEN** 玩家在物品栏查看弹幕武器
- **THEN** 图标呈枪形轮廓而非抽象色块，与武器"发射弹幕"的用途相符

### Requirement: 武器装入面板核心嵌武器视觉
武器装入 GUI 底图 SHALL 重绘为武器主题面板：三核槽背景各嵌入半透明暗化的弹幕铳图案（静态嵌底图，非动态渲染），装入核心后核贴图叠加其上，形成"核心装入武器"的视觉隐喻。三槽旁 SHALL 有槽位类型小标注（弹核/等级核/增幅核，语言键中英双备）。

#### Scenario: 空槽见武器轮廓
- **WHEN** 打开未装核的武器装入界面
- **THEN** 三个槽位背景可见暗化的武器图案

#### Scenario: 装核叠加呈现
- **WHEN** 向弹核槽装入任意弹核
- **THEN** 核物品图标渲染于武器图案之上，视觉上呈嵌入武器状
