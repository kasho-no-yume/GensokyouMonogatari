# 源初造化之仪实机验收清单（交用户，agent 不启动客户端）

现有 `_run_ritual_test.ps1` harness 仅认 generator_circle 形状，本仪式按下列人工流程评审。
测试区惯例：`(104, 100, 20)` 附近平整地面。

## 1. 搭建与开槽

1. 创造模式，`/reload` 后手持仪式构建器选 `gensokyou:zaohua_circle`、品阶按阶级，一键搭建 0 阶。
2. 右键核心 → GUI 应显示：**灵力核心槽可见**（供能入口）、右侧「开始合成」按钮、
   无通用启停按钮（pattern 保持 `toggleable:false`）。
3. `/give @s gensokyou:spirit_core_0[gensokyou:spirit_core_power={stored:20000L}]`
   装入槽内（应能放入/随时取出/shift 转移）。

## 2. 合成主流程（配方一）

1. 8 个祭品台各放 1 件：4×钻石 + 4×0 阶仪式石。
2. 点「开始合成」→ 应见：聚灵进度行（1Hz 刷新）→ 足额后原料逐台起飞、
   绕核螺旋内收升高、紫色拖尾、**全结构紫粒子升空约 5 秒** → 核心上方烟花爆散+音效 →
   产物 1×1 阶仪式石落地可拾取。
3. 台数守恒：产物落地后台面 8 台全空。

## 3. 最大匹配语义

1. 台面放 4钻+4石0+**1 个多余圆石** → 仍命中（max 不报"多余物品"），合成后圆石留台。
2. 两条配方互不干扰：8×碎符卡星 时匹配 `broken_spell_card_star` 配方（spCost 8000）。
3. 0 阶结构（8 台）放不下 9 件原料属正常——材料件数即天然阶限。

## 4. 触发与门控

1. 红石：核心旁放红石块（邻居信号 0→>0）→ 触发一次合成；保持常亮不再触发；
   拿掉重放 → 再触发一次。**飞行期间**再点按钮/再脉冲 → 无响应，按钮置灰。
2. 聚灵中点「开始合成」→ 取消聚灵（提示"已取消…不退还"），已抽灵力不回滚。
3. 聚灵中取走任一原料 → 中止，提示配方破坏，原料剩余不动、灵力不退。

## 5. 防吞件与恢复

1. 飞行中拆核心方块 → 全部在飞原料在轨迹当前位置落地；槽内灵力核心随方块掉落。
2. 合成期间退出世界重进（区块卸载重载）→ 演出/聚灵进度延续，无卡死无吞件。
3. 八方归元与万象共鸣核心 GUI：**无**灵力核心槽；加具土命槽仍为注灵方向（缓存→核）。

## 6. 供能链路（有万象共鸣网络时可选）

1. 共鸣塔把源初造化列为受灵汇 → 核心自身储灵增长（信息头 SP 行可见）；
2. 槽核抽空后合成靠注入灵力续聚（三段式：槽核→自身储→周围）。

## 期望日志（启动期，run/logs/latest.log）

- `Loaded N ritual recipes`（N ≥ 2）且无 `Rejected ritual recipe`；
- 两条造化配方签名不相容（ingredient 集合不同），**不应**出现 `properly contain` WARN；
- 无 registry 错误、无 zaohua 相关异常。
