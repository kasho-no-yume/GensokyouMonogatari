# ritual-power-attributes 增量

## MODIFIED Requirements

### Requirement: 端点速率行为声明
`RitualBehavior` SHALL 提供灵力端点属性声明钩子：最大每秒输入速率与最大每秒输出速率，默认均为 0（无属性）。声明 SHALL 可依据当前 `RitualMatch`（阶级）计算。具体数值 MUST 由该仪式的配置基项或其所托管物品的构造定值聚合驱动，而非在行为中硬编码字面量。端点"最大输出速率"SHALL 是该仪式的**对外供灵能力**声明，MUST NOT 与仪式内部产灵/吞吐速率直接语义等同——二者 MAY 由各自独立配置基项驱动（即便当前取值相同，也 MUST 分道声明与折算，MUST NOT 复用同一 UI 行或同一取值通道表述两件事）。

#### Scenario: 无属性默认
- **WHEN** 一个既有行为未覆写速率钩子
- **THEN** 其 in/out 速率均为 0，不能被任何路由机制选作端点

#### Scenario: 随阶级变化的速率
- **WHEN** 加具土命之焰处于 3 阶
- **THEN** 其 out 速率声明为该仪式"供灵输出基项"配置在 3 阶的值（随阶级放大），而非固定数字

#### Scenario: 产灵速率与供灵上限分道
- **WHEN** 查阅加具土命之焰的产灵速率式与其 `spiritOutRatePerSecond` 声明
- **THEN** 两者由各自的配置基项驱动（默认取值相同、公式独立），不存在"改产灵必改供灵上限"的硬绑定

#### Scenario: 托管聚合速率
- **WHEN** 八方归元之仪台上托管着若干被识别的灵力核心
- **THEN** 其 in/out 速率声明等于这些核心自身速率之和（数值来自物品定值，无仪式侧配置）
