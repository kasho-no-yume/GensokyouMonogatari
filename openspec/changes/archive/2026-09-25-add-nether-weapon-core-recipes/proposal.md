## Why

当前弹幕主武器可在 0 阶普通合成中直接制作，而全部弹幕核、武器等级核、增幅核和灵力核心尚无完整生存获取链，导致「下界发展仪式 → 获得幻想乡材料 → 铸造弹幕武器」的核心玩法循环没有真正闭合。本变更把主武器与前中期核心统一纳入源初造化之仪，并让指导书在对应物品词条中直接展示准确配方，使战斗成长与仪式科技侧形成清晰闭环。同时必须保留 0 阶灵力核心作为唯一的无灵力 bootstrap 路径，避免「造灵力核心本身需要灵力」导致开局死锁。

## What Changes

- 移除弹幕主武器的 0 阶普通工作台直造路径，改为 1 阶源初造化之仪产出：1 阶仪式石、灵铁、下界合金锭、符卡星与 P 点共同构成一次性的武器框制造门槛。
- 明确采用「中门槛」：只要求玩家建成并运行相应阶级的源初造化之仪，不记录仪式是否在下界现场执行，也不新增维度访问历史状态。
- 将本变更范围内的全部核心改为源初造化仪式产物，而非普通工作台配方：T1/T2 五种弹幕核、Lv.1/Lv.2 等级核、T1/T2 增幅核、灵力核心 1～2 阶。
- 0 阶灵力核心作为唯一的 bootstrap 例外，保持工作台无序合成（4×0 阶仪式石 + 4×P 点 + 1×紫水晶块），不消耗灵力且不依赖任何仪式供灵手段。
- 依据物品定位区分仪式费用：一次性武器框、等级核和增幅核费用较高；可重复使用的灵力核心控制在中低费用，灵力核心 1 阶固定为 20,000 灵力。
- 增幅核随机词条继续由既有 `RuneGenerator` 生成；本变更不实现属性洗练仪式，增幅核洗练另立后续变更。
- 源初造化仪式指导词条继续保持不展示配方；新增对应物品 Patchouli 词条，通过稳定配方 ID 精确展示各自源初造化配方，避免开放式配方列表和排序索引问题。
- 3～5 阶武器核心、弹幕核以及灵力核心 3～5 阶不在本变更范围内，等待高阶材料生产链落地后另行设计。

## Capabilities

### New Capabilities
- `danmaku-weapon-crafting`: 定义弹幕主武器框、T1/T2 弹幕核、武器等级核与增幅核的源初造化获取路径、费用和对应物品词条展示。
- `spirit-core-crafting`: 定义灵力核心 0～2 阶的获取路径（0 阶为无灵力工作台 bootstrap，1～2 阶为源初造化）、独立供能边界及对应物品词条展示。

## Impact

- 数据：删除 `data/gensokyou/recipe/danmaku_weapon.json`，新增 `recipe/spirit_core_0.json` 作为无灵力 bootstrap，并在 `ritual_recipes/zaohua_circle.json` 新增 12 条实物产物配方。
- 仪式：源初造化由 5 条增至 17 条；新增配方全部使用既有 `activation + match:max + minTier + spCost + result` 协议。
- 指导书：源初造化条目继续隐藏配方；新增 13 个物品词条，其中 12 个使用按配方 ID 定位的仪式配方卡，0 阶灵力核心使用 Patchouli 工作台配方页。
- 客户端：`RitualPageComponent` 增加稳定 `recipe` ID 选择模式，保留既有 `recipe_index` 兼容路径。
- 经济：T1/T2 幻想乡材料、符卡星、下界合金与仪式灵力消耗成为战斗模块的主要投入；1 阶及以上灵力核心保持独立电池经济，0 阶核心不消耗灵力以保证开局可启动。
- 兼容：弹核行为、武器伤害公式、装配台三槽、等级闸门与词条预算均不变；已有武器和核心 NBT 不迁移。
- 依赖：T2 配方的可达性依赖现有 T2 材料链；若 `sukima_fragment` 等来源尚未闭合，不在本变更中顺带修复。
