## Context

弹幕主武器、6 种弹幕核、3 种武器等级核、3 种增幅核与 6 阶灵力核心均已注册；现有主武器可由普通工作台制作，全部核心没有生存配方。源初造化之仪已经支持 `minTier`、`spCost` 与实物 `result`，而且每个祭品台一台一件，因此本变更把所有新增产物统一放入该仪式，避免普通 3×3 配方的槽位上限问题。

本变更选择用户确认的「中门槛」：主武器框必须通过 1 阶源初造化之仪式获得，但不要求玩家进入过下界、不要求仪式在下界现场运行，也不新增永久维度历史状态。用户进一步确认：本轮范围内除 0 阶灵力核心外的全部核心均进入源初造化，指导书不在造化条目列出配方，而在每个物品词条中显示对应配方；增幅核洗练另立变更。

0 阶灵力核心是唯一例外：最早期仪式只能手动装填灵力核心，若核心本身也必须由仪式产出，则没有任何灵力来源，开局直接死锁。因此它保留为不消耗灵力的工作台配方，作为启动整个供能链的 bootstrap。

## Goals / Non-Goals

**Goals:**

- 用源初造化仪式替换主武器的 0 阶普通合成路径。
- 补齐 T1/T2 弹幕核、等级核、增幅核和灵力核心 1～2 阶的仪式获取配方。
- 保留 0 阶灵力核心为无灵力工作台配方，保证开局仪式供能链可启动且不产生死锁。
- 按一次性物品与常用电池区分仪式灵力费用。
- 为每个新增产物建立独立 Patchouli 物品词条，并按稳定配方 ID 展示配方。
- 保持既有弹核行为、武器等级、词条预算、伤害公式与装配台交互不变。
- 让每个 mod 独有配方至少包含一件 mod 材料，并让阶级核心使用对应阶级材料。

**Non-Goals:**

- 不记录或校验“是否进入过下界”“是否在下界运行仪式”。
- 不新增第二个锻造界面，也不把装配台扩展为制造站。
- 不实现增幅核属性洗练仪式；该内容另立变更。
- 不设计 T3 激光炮核、Lv.3 等级核、T3 增幅核及灵力核心 3～5 阶配方。
- 不修复祭品台、灵炭、隙间碎片或其他既有生存链断点。
- 不修改弹幕核射速、倍率、灵力成本、武器等级倍率或词条数值。

## Decisions

### 1. 主武器框采用 1 阶仪式 capstone

新增 `zaohua_danmaku_weapon_frame`：

- `ritual_stone_1 ×1`
- `spirit_iron ×2`
- `netherite_ingot ×1`
- `spellcard_star ×1`
- `ppoint ×4`
- `minTier = 1`
- `spCost = 20000`
- `match = max`
- 输出 `danmaku_weapon ×1`

删除 `data/gensokyou/recipe/danmaku_weapon.json`，不保留普通工作台替代路径。选择下界合金锭而非碎片，是因为系统只有一把无耐久主武器，锭是一次性 capstone 成本。

### 2. 除 bootstrap 外的范围内核心均使用源初造化仪式

普通工作台每条配方最多占 9 个槽，无法承载散弹玉、增幅核与灵力核心 1 阶的既定材料数量，因此除 0 阶灵力核心外，本变更不新增任何核心普通合成文件。源初造化由 5 条增至 17 条，但其指导书条目继续显式 `show_recipes:false`；JEI 仍按既有页签展示全部仪式配方。

0 阶灵力核心是唯一的 bootstrap 例外，配方为 `crafting_shapeless`：`ritual_stone_0 ×4`、`ppoint ×4`、`amethyst_block ×1`，共 9 件、无灵力消耗、不依赖仪式。

### 4. 等级核与增幅核按一次性 capstone 定价

| 产物 | 原料 |
|---|---|
| 武器等级核 Lv.1 | 1 阶仪式石×1、石英块×1、红石块×1、P点×4 |

### 5. 灵力核心是低频费用、高频使用的电池

| 产物 | 获取方式 | minTier | 原料 | spCost |
|---|---|---:|---|---:|
| 灵力核心 0 阶 | 工作台 | — | 0 阶仪式石×4、P点×4、紫水晶块×1 | 0 |
| 灵力核心 1 阶 | 源初造化 | 1 | 1 阶仪式石×1、灵铁×1、灵魂砂×4、下界石英×4 | 20,000 |
| 灵力核心 2 阶 | 源初造化 | 2 | 2 阶仪式石×1、星银×2、潮汐晶×1、隙间碎片×1 | 50,000 |

0 阶配方用满 9 格无序槽且不消耗灵力：它必须在任何仪式供能手段出现之前可制作，否则灵力核心会成为不可解的循环依赖。T1 最大需求为 11 件，适配 16 个祭品台；T2 最大需求为 12 件，适配 24 个祭品台。

灵力核心不作为主武器框或弹幕发射的强制前置；玩家灵力池仍是武器消耗来源，灵力核心只服务仪式 GUI、缓存与供能链。

### 6. 指导书使用精确配方 ID 的物品词条

源初造化条目保持 `no_recipes=true`，不展示 17 条配方。批量生成器额外为 13 个新增产物建立物品词条：

- 战斗类 10 个：主武器、5 种弹幕核、Lv.1/Lv.2 等级核、T1/T2 增幅核，归入 `gensokyou:weapons`。
- 供能类 3 个：灵力核心 0～2 阶，归入 `gensokyou:items`。

每个词条包含 spotlight 说明页和一张配方页：12 个仪式产物使用 `gensokyou:ritual_page`，通过 `recipe` 变量传递完整 `gensokyou:<recipe_name>`，由 `RitualPageComponent` 按 ID 查找，不再依赖会随排序变化的 `recipe_index`；0 阶灵力核心使用 Patchouli 内置 `patchouli:crafting` 展示工作台配方。既有仪式条目继续使用 `recipe_index`，保持兼容。

词条门槛沿用配方 `minTier` 的世界进度映射：0 阶常驻，1 阶挂 `guide/nether_unlock`，2 阶挂 `guide/end_unlock`，并以 secret 方式隐藏。0 阶灵力核心无仪式门槛，常驻可见。

### 7. 展示与本地化复用现有管线

- JEI 继续自动展示源初造化全部 17 条配方。
- 指导书生成器增加 `--items-only` 模式，只重建本变更的物品词条，避免无关仪式条目产生批量差异。
- `RitualPageComponent` 同时支持 `recipe` 精确 ID 与旧 `recipe_index`。
- 物品词条名称直接复用 `item.gensokyou.*`，仅新增共享说明文本与各配方 JEI 键。

## Risks / Trade-offs

- **T1/T2 精炼材料依赖未闭合链路** → 以精炼辰砂、灵铁、星银为正式接口；缺失时记录阻塞，不静默替换为原矿。
- **T2 隙间材料当前可能无来源** → 仍定义正确配方，但可达性验证必须明确失败；不顺带扩大变更修复。
- **除 bootstrap 外核心进入造化仪会提高重复更换成本** → 用户已选择仪式化；弹核费用低于等级核/增幅核，灵力核心维持相对低频费用。
- **把 0 阶灵力核心也仪式化会造成开局死锁** → 它保留为不消耗灵力的工作台配方；核心 1～2 阶仍需仪式产出，不影响后续供能链设计。
- **源初造化配方总数超过指导书 12 页阈值** → 造化条目继续隐藏配方；每个物品词条只按稳定 ID 指向自己的配方。
- **灵石核心 1 阶当前依赖灵炭等未闭合链** → 保持正式材料接口并记录为已知可达性风险。
- **旧存档中已有主武器** → 不回收、不失效；仅移除新的普通制作路径。
- **配方数量与材料经济可能失衡** → 实施时审计每条配方的 mod 料、阶级料、祭品台容量和 T1 产量，不调整战斗数值。

## Migration Plan

1. 删除普通主武器配方，新增 0 阶灵力核心的无灵力工作台配方。
2. 在源初造化中加入 12 条实物产物配方。
3. 扩展 Patchouli 生成器与配方卡组件，生成 13 个物品词条。
4. 验证新玩家不能普通直造，但可在对应阶级造化完成后获得目标物品。
5. 验证已有主武器与核 NBT、装配和发射行为不受影响。
6. 回滚时删除新增仪式条目与物品词条、删除 `recipe/spirit_core_0.json`、恢复 `danmaku_weapon.json`；已发放物品无需迁移。
