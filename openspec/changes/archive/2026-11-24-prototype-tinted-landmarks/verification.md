# 地标技术样件验收

在启用命令的测试世界中执行 `/gs_landmark_sample install` 和 `/gs_landmark_sample visit`。前者在 `gensokyou:landmark_sample_v1` 安装模板，后者传到门外。样件占用 `x=12..23, y=64..70, z=4..11`。

- 在外墙 `(14,66,5)`、`(15,66,5)`、`(16,66,5)` 观察灰色、浅红、深红。后两格使用相同的方块状态，分属两个区块。离开视距再回来、重新进入世界后对照这三格。
- 在生存模式下试挖灰模并右击门。分别在室内、从边界外向内和保护区外放置。用床从外向里跨界放置，确认两个位置都未留下方块。
- 在样件外布置 TNT、黏性活塞和整合包使用的 Mekanism 激光，确认灰模不移动、不消失。在区域外用普通方块做对照。
- 在门外启动灵力筑基器，让清地和铺地范围跨过边界，确认设备只修改保护区外可修改的方块。

`python tools/export_landmark_sample.py --check` 核对模板、配色和模型与图纸一致。`runLandmarkSampleProbe` 使用独立的专服测试存档核验模板、门的状态切换、爆炸、活塞可推性和放置事件。
