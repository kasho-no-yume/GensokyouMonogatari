# 魔法森林巨木与三阶自然素材 · 审阅稿

## 魔法森林巨木

**星冠木**（暂名）以原版巨型丛林树为尺度参考。树干粗 2×2、高约 18～28 格，深靛色树皮带浅灰纵纹。分枝从树干上半段斜伸，约 9～13 格宽的树冠分两至三层，叶面以深青绿为主，冠缘略偏蓝紫。从林下能看见粗树干和枝杈，从高处能看见连成片的树冠。

森林内部以巨木为主，现有魔法木留在林缘与林下。巨木密集处可让相邻树冠接触，低处留自然林窗、通行空间和地标净空。先用固定种子看远景和林下视角，再调整树高与密度。首个原型可以复用原版巨型树放置机制，自定义树形参数、方块和贴图。

## 各群系的独特素材

博丽神社和人间之里使用通用素材。其余六个陆地区各有一组，红魔馆陆地与雾之湖分别配置，三途川也有独立的一组。表中的专属指原生采集地。树苗、种子和根株取得后可带走，在合适的基底上栽培。矿床是有限资源，按地貌布点，让玩家能用地表线索找到第一批素材。

| 群系 | 特色植物或菌类 | 特色矿物 | 找寻线索 |
| --- | --- | --- | --- |
| **守矢山** | **山风龙胆**（沿用龙胆）。高处草坡成片的靛蓝钟形花，采花后用现有龙胆种子栽培。花可做高山药剂的原料候选。 | **风纹云母**（新）。岩缝中有浅青色薄片，镐采得云母片，可做透光屏风和灯罩。 | 沿绿坡向上找成片龙胆，再检查邻近转折处的露岩。 |
| **魔法森林** | **星冠木**（新）与**野生魔法菇**（沿用）。巨木产建筑木材和三阶木构件基材，四株树苗培育巨木。林下魔法菇提供现有药材或种源。 | **墨辉石**（新）。腐殖土下的浅岩层里有黑底紫边的矿团，磨成颜料可做深色墨或绘制装饰纹样。 | 看见巨冠后，在背阴树根附近找菇，沿洼地侧壁找浅矿。 |
| **迷途竹林** | **月节笋**（新）。月白节、淡绿尖的小笋，出现在腐殖土和竹根交界。采嫩笋做食材，留种可在竹荫下繁殖。 | **节纹玉**（新）。浅沟下方的青玉石团带竹节状横纹，开采后可抛光成青碧镶条和建筑嵌片。 | 竹林里先找林窗旁的低沟，沿沟壁找露出的环纹石。 |
| **白玉楼** | **常世木**（沿用）。疏朗白樱自然生成于台地，树苗可带走。原木作白色建筑木材，树下落瓣可剪取作装饰。 | **雪髓晶**（新）。白玉岩断面中的半透明乳白晶簇，可磨作乳白釉料，给陶饰上釉。 | 先看台地上的白樱，沿台阶边缘找晶簇露头。 |
| **地灵殿裂谷** | **幽光蕈簇**（沿用）。长在裂谷洞口和暗岩避光面，可整簇采下，移栽成低亮度的洞穴路标。 | **鸣晶矿**（新）。暗岩中的短簇青紫晶体，深层矿带暂定 Y=-48～-16。镐采得鸣晶碎片，可做三阶共鸣构件。 | 蕈簇提示可通行的洞口和岩架，矿带在裂谷下方，需从安全岩架往下开掘。 |
| **红魔馆陆地** | **绯露蔷薇**（新）。林边低矮的暗红花灌木，剪下花枝可扦插。花瓣可调制绯红染料，整株用作花篱。 | **蔷薇石榴石**（新）。背湖坡的浅岩中有透明绯红晶粒，采得原晶，可切磨成嵌饰，用于饰件和红色玻璃装饰。 | 顺着背湖坡的蔷薇花丛找岩口，花篱和矿石都能从岸上取得。 |
| **雾之湖** | **雾湖芦苇**（沿用）。湿沙边成束生长，割上段留根再生。纤维用于编织三阶符纸的纸胚，也可作编席和滨水装饰。 | **雾纹水晶**（新）。近岸清浅水底的石块中露出带乳白雾带的浅蓝晶面，短潜即可开采，抛光后可做雾面玻璃和灯罩。 | 先从岸上看芦苇带和浅水中的蓝白晶面，矿点可游泳往返。 |
| **三途川** | **渡灯藻**（新）。生在近海礁石上的深蓝藻叶，叶尖呈淡金色。剪叶留根可再生，带回水槽可作水下灯饰。 | **冥砂铁**（新）。外海水下沙丘中的黑砂透出金属点，用铲采后筛出黑砂铁粒，可做深色的船锚、链环和压重件。 | 划船经过近岸藻带后，再到外海寻找黑砂斑，藻带和砂矿分别能从浅水与船上辨认。 |

## 首次采集与用途

- **每区两种采集体验。** 植物或菌类通常从地表可见，带回种源能持续获取。矿物按山脊露头、浅沟石团、台地断层、深矿、浅水晶簇和外海砂层分布。地灵殿保留向下开掘的体验，雾之湖和三途川分别提供短潜和乘船找矿。
- **采到就有用途。** 木材、花枝、蕈簇、藻类与部分矿块可直接布置。切磨、筛取和上釉是后续加工候选，具体用现有工作台或加工流程时再确定。配方可按用途分别消耗星冠木、芦苇纤维和鸣晶，避免一件三阶产物要求跑遍所有群系。
- **保留采集辨识度。** 既有龙胆、常世木、魔法菇、幽光蕈簇与雾湖芦苇直接纳入候选。彼岸花可继续作为白玉楼与三途川共用的地貌点缀。用表中的专属素材建立采集目的地，灵铁、辰砂和星银仍作为既有矿物供给。

首版已接入自然生成、素材掉落、星冠木板制作以及可栽种的星冠木和常世木。表中各加工用途是消费端配方的设计方向。生成密度以实景复查为准。

## 各群系的纯装饰植被

覆盖八个陆地区、雾之湖和三途川。每个群系暂拟三种装饰，名称均为暂名。装饰可收集并重新摆放，均以观赏为用途。树冠、竹群、落樱和芦苇分别作为已有方案中的景观主体，新植物填充树下、岩壁、湿岸和水底等不同位置。

| 群系 | 植被候选 | 分布与远近景 |
| --- | --- | --- |
| **博丽神社** | **绯梢枫**，矮冠薄叶，绿叶到枝尖渐成朱红。**铃穗草**，柔弯草梗上垂两三朵乳白小花。**碎红枫叶**，贴地错落的掌形落叶。 | 红枫三两株点在参道外围的土坡和林缘，落叶偏向树冠下坡侧。铃穗草沿林地转草坡的位置成短簇，庭院和参道保持开阔。 |
| **守矢山** | **云背杜鹃**，伏地团状灌木，青绿枝叶间带淡桃花。**风旗芒**，叶和银穗朝同一侧贴斜。**岩扇苔**，灰青色小扇片贴住岩边。 | 山腰用杜鹃点缀云杉林缘，开阔山脊用断续银穗带标出坡折，岩扇苔沿陡坡脚和背阴石面少量生成。远看仍是连贯绿坡。 |
| **魔法森林** | **蓝边卷蕨**，近一格高的外展叶片，叶尖卷起，暗绿叶缘带蓝。**垂珠藤**，从粗枝底下垂落的断续细藤，夹少量淡紫苞。**扇耳菌**，叠瓦状棕紫菌片，贴在粗树干侧面。 | 星冠木形成主冠，卷蕨在树根外侧成团，扇耳菌零散长在背阴树干。藤幕偏向林窗边缘，林窗中心和树间低处留出通行带。 |
| **迷途竹林** | **折扇竹叶**，贴地的淡赭色竹叶层。**青斑麦冬**，拱形窄叶，叶尖有浅青小斑。**雾绒莎**，淡灰绿的蓬松穗头，叶丛不足一格高。 | 叶层在密竹脚下聚成斑块，麦冬沿竹丛边缘围出曲折线条，雾绒莎扎在浅沟湿底。林窗继续低矮而明亮，远景由高竹主导。 |
| **白玉楼** | **垂雪藤**，灰白小花串从白玉岩的壁沿垂下。**浅墨苔**，平贴岩面的灰紫圆斑。**月白石竹**，银灰细叶上托乳白星形小花。 | 白樱冠和落瓣保留在台地顶，藤从少数台阶边缘短垂，浅墨苔散布在背阴断面，石竹沿台地内侧成簇。大片裸白岩形成留白。 |
| **地灵殿裂谷** | **烬纹地衣**，暗岩侧面的铜橙细裂纹。**灰绒伞菌**，岩架阴面长出的矮平灰伞，一簇几个。**黑须根**，洞顶裂缝垂下的黑褐细根。 | 由洞口的断续地衣过渡到内侧岩架上的菌群，细根仅在少数有余高的洞顶出现。裂谷大面保留裸岩，亮色集中在可近看的一小段岩面。 |
| **人间之里** | **柳梢灌木**，低垂的嫩黄绿窄叶形成稀疏小冠。**田沿雏菊**，矮叶间点缀白瓣黄心。**金穗画眉草**，细梗托着疏松的淡金草穗。 | 柳梢灌木成小群长在低洼湿地边，雏菊沿草甸边缘成片，金穗草集中在向阳缓坡。保留连续的低草地与开阔视线，方便看见村落和后续田块。 |
| **红魔馆陆地** | **紫穗鼠尾草**，深紫花穗立在灰绿叶簇上。**酒叶地锦**，背湖坡石面上的酒红五瓣叶。**灰叶卷柏**，低矮圆团状的银绿叶丛。 | 向阳坡用紫穗草分成几个花坡，酒叶地锦集中在林缘露岩，卷柏稀疏围在暗红蔷薇和灰岩之间。靠建筑预留地逐渐降低高度与覆盖率。 |
| **雾之湖** | **薄雾睡莲**，贴水深绿圆叶，少数开淡蓝小花。**银线水草**，浅水下直立的银绿带形叶。**淡蓝湿岸鸢尾**，剑形叶托起小朵蓝花。 | 从岸边鸢尾和芦苇过渡到有间隙的睡莲片，再到可从水面看到的水草带。装饰集中在避风浅湾，湖心与常用下水点留出连通的开阔水面。 |
| **三途川** | **白须盐草**，潮线干沙上的低矮银灰草束。**烟紫扇藻**，附在暗礁侧面的扇形藻片。**沉青丝藻**，深处沙纹间贴底延伸的青黑丝带。 | 从干沙上的零散盐草往外，近岸礁石偶见紫色扇片，再往深水只留下斑驳沉藻。水面保持空旷，近岸礁带和深水沙底各有一套轮廓。 |

### 铺设与审阅

- **随地貌成片。** 让林窗、山脊、浅沟、岩壁和水深决定植被组合。同一群系应能看到密集植被、稀疏过渡和裸地。近邻群系边缘逐渐稀释各自的主植被，通用草本可延续到两侧。
- **从多个视角看。** 远景看树冠、花坡或水岸色带，中景看高矮与疏密，步行和潜水视角看落叶、石面和水底的小形态。颜色相近的群系用分布区分，例如雾之湖以水面浮叶和浅水草带为主，三途川的图案集中在潮线和水底。
- **沿真实路线验收。** 每区看典型内部地形、群系边缘和地标附近各一段，雾之湖与三途川各看一次水面和水下。检查地标净空、步行视线、船行水面以及特色资源露头是否清楚。
