# ritual-pattern-system Delta

## MODIFIED Requirements

### Requirement: 声明式结构定义
仪式结构 SHALL 以 JSON 定义于 `data/gensokyou/rituals/`：palette 谓词（精确方块/#标签）、按层级组织的**增量**方块偏移表——每层为 `{level, adds}`，`adds` 各项为**位置式数组** `["key",x,y,z,o?]`（相对锚点的稀疏偏移，仅存对称规范四分之一，加载期四重展开；第 5 位为可选朝向常量）。`adds` SHALL 只声明**该级新增**的格位；loader SHALL 按 level 升序将各级增量累积为全量层级切片，供匹配器、构建器与仪式逻辑以既有全量语义消费（下游零感知）。全文件唯一的 anchorKey 对应仪式核心，其条目 SHALL 仅出现在最低级的增量中。对象式条目（v3 格式）与全量快照层级字段（v4 `blocks`）SHALL NOT 再被接受：出现即拒载，日志 SHALL 报明文件名并提示迁移方式。结构经资源重载监听器加载，`/reload` 热生效。

#### Scenario: 热加载
- **WHEN** 新增或修改 rituals JSON 后执行 /reload
- **THEN** 新结构定义立即可用于匹配，无需重启

#### Scenario: 四分之一展开
- **WHEN** 某级增量仅声明轴位 `["S",0,0,1]` 与对角位 `["S",1,0,1]` 两个方块条目
- **THEN** 该级累积切片展开为核心四周 4 个与四角 4 个共 8 个方块位置

#### Scenario: 增量累积为全量切片
- **WHEN** 最低级增量声明 `["S",0,0,3]`，二级增量声明 `["S",0,0,5]`
- **THEN** 二级累积切片同时包含 (0,0,3) 与 (0,0,5)，且匹配、构建等下游行为与 v4 全量快照完全一致

#### Scenario: 核心仅最低级声明
- **WHEN** 某仪式 pattern 的 anchorKey 条目 `["C",0,0,0]` 只写在最低级增量中
- **THEN** 全部层级累积切片均含且仅含该核心格位，高级增量无需重复声明

#### Scenario: v4 快照拒载
- **WHEN** 某层级仍使用 `"blocks": [...]` 字段（全量快照写法）
- **THEN** 该文件被拒绝加载，日志指出 v4 快照已废弃并给出迁移指引

### Requirement: 加载期构造性校验
对称约定 SHALL 由存储格式构造性保证（四分之一展开）；**纯增量与锚点唯一性 SHALL 构造性校验**。loader SHALL 拒绝以下文件并在日志报明文件名、格位与原因：
- 某级增量四重展开后，与更低级累积切片出现**任何格位相交**（含同字符重复声明，即对低级结构的重复登记或改写）；
- anchorKey 全文件缺失、出现多于一次、不在原点、**y≠0**、或出现在非最低级的增量中；
- 某一 level 号重复出现；
- 带朝向的条目：锚点格不带朝向、AIR/IGNORE 谓词格不带朝向、EXACT 方块满足所声明常量的属性需求、`o` 值可解析（id ∈ 1-26 或名在词表内）、条目为合法形状的位置式数组。

合规文件 /reload 热生效不受影响。

#### Scenario: 增量冲突拒载
- **WHEN** 二级增量声明 `["S",0,0,3]`，而 (0,0,3) 已在最低级累积切片中
- **THEN** 该文件被拒绝加载，日志指出冲突格位与来源层级

#### Scenario: 锚点异常拒载
- **WHEN** 某增量文件中 anchorKey 缺失、出现多于一次、位于非原点偏移、带非零 y、或出现在非最低级增量中
- **THEN** 该文件被拒绝加载，日志说明原因

#### Scenario: level 重复拒载
- **WHEN** 某 JSON 存在两个 `level` 号相同的层级对象
- **THEN** 该文件被拒绝加载，日志指出重复的 level 号

#### Scenario: 非法朝向拒载
- **WHEN** 某条目第 5 位为 `99`（超出常量表）
- **THEN** 该文件被拒绝加载，日志指出格位与非法值

#### Scenario: 墙类声明朝向拒载
- **WHEN** 某 EXACT 条目指向 `minecraft:stone_wall` 并声明任意朝向常量
- **THEN** 该文件被拒绝加载，日志指出该方块不满足常量的属性需求

#### Scenario: 旧对象格式拒载
- **WHEN** 某条目仍写作 v3 对象 `{"key":"S","x":0,"y":0,"z":1}`
- **THEN** 该文件被拒绝加载，日志指出条目须为数组格式

#### Scenario: 合规热载
- **WHEN** 修改合规 JSON 后执行 /reload
- **THEN** 新定义立即生效，无告警

#### Scenario: 等价迁移
- **WHEN** 对既有 v4 pattern 运行迁移转换（逐级集合差拆分为 v5 增量）
- **THEN** 转换器断言 v5 各级累积切片与原 v4 快照逐格位一致，全部既有仪式匹配行为不变
