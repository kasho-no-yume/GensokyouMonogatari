# Design: 前期进度门与仪式石配方重排

## Context

当前前期有两条互相独立的进度轴被混在一个「结构阶 → 世界进度」门槛里：

- **材料带**：指导书（T1 材）/ 隙间碎片（T2 材）
- **结构阶**：T0 仪式石 / T1 仪式石 / T2 仪式石
- **玩家阶**：八百万神恩 1–5 阶

三者并不等价。旧配方的错位正来自把它们当成同一条轴：

- 1 阶石挂在 0 阶造化，但材料要 1 阶造化才能产的灵炭；
- T2 材料带挂在隙间碎片，而隙间碎片要 2 阶结构才能召的八云蓝；
- 书页按「结构阶 = 下界/末地」解锁，但材料与结构的实际门槛不同。

本变更把三轴拆开，并让配方门槛与书页门槛一一对应。

## Goals / Non-Goals

**Goals**
- 拆掉 0→1 与 1→2 的两个配方闭环；
- 让 T1 石 / T2 石的材料量级与对应阶源初造化的台位数匹配；
- 让书内门槛与配方门槛一致（材料带 / 结构阶 / 玩家阶分开）；
- 顺手修正 README 与 project.md 的飞行描述。

**Non-Goals**
- 不改玩家符卡数值（另立 `buff-player-spellcards`）；
- 不新增 BOSS 生成通路、不复活芙兰/琪露诺/霖之助；
- 不改 3 阶以上的仪式石配方（本变更只为 1/2 阶定调，3+ 按同一不变量后续推导）。

## Decisions

### D1 三轴门槛模型

| 轴 | T1 | T2 | 载体 |
|---|---|---|---|
| 材料带 | 指导书 | 花精之滴 | 资源仪式祭品台信物，不消耗 |
| 结构阶 | 黑石（下界） | 紫珀块（末地） | 1/2 阶仪式石配方 |
| 玩家阶 | 1 阶进阶 | 2 阶进阶 | 八百万神恩，灵力量级 |

书页门槛 SHALL 按它讲的内容选轴，MUST NOT 一律按结构阶挂：

- 材料词条（星银/潮汐晶）挂材料带门槛；星银页直接用 `nether_unlock`，
  不新建 advancement；
- 结构/仪式词条挂结构阶门槛；
- BOSS 条目按 `bossTier()`；
- 玩家阶相关（神恩）挂对应世界进度或玩家阶，二者取其一并写明。

### D2 1 阶石：用凡材做维度门，不用灵炭做闭环

`zaohua_stone_t1`：

```
1 diamond + 2 ritual_stone_0 + 1 cinnabar + 4 blackstone → 1 ritual_stone_1
minTier 0 · spCost 2,000 · Σcount 8
```

- 去掉 `refined_cinnabar`，灵炭不再是 1 阶石前置；
- `blackstone` 是下界凡材，承担「T1 = 下界」的维度门，且不引入新的 mod 材料；
- `cinnabar` 是 T1 mod 材，满足「阶级物品含 mod 材」的素材规则；
- `Σcount = 8` 恰好填满 0 阶造化的 8 台。

### D3 2 阶石：用 T2 材料带 + 末地凡材做双门

`zaohua_stone_t2`：

```
2 ritual_stone_1 + 4 spirit_iron + 1 tide_crystal
+ 1 spirit_herb + 1 gentian + 1 higanbana + 6 purpur_block → 1 ritual_stone_2
minTier 1 · spCost 20,000 · Σcount 16
```

- 去掉 `star_silver`，避免「2 阶石要 2 阶材料带、2 阶材料带要蓝、蓝要 2 阶石」的环；
- `tide_crystal` 是 T2 mod 材，`purpur_block` 是末地凡材，两者分别承担材料带与结构阶门；
- 三种植物把农业仪式纳入 T2 成本，避免 2 阶石只吃矿物；
- `Σcount = 16` 恰好填满 1 阶造化的 16 台。

### D4 产出数量：2 阶石 4 块/次

两条 T1 配方按 **1 块/次**，2 阶石按 **4 块/次** 固化。结构需求是：

| 结构 | 2 阶石数量 |
|---|---|
| 八方归元 | 2 |
| 万象共鸣 | 15 |
| 结界引爆 | 15 |
| 合计 | 32 |

按 4 块/次，32 块 2 阶石只需 8 次合成：

- 16 块 1 阶石（= 16 钻石 + 16 辰砂 + 64 黑石 + 32 块 0 阶石）
- 32 灵铁（= 32 原矿 + 32 灵炭）
- 8 潮汐晶
- 24 株植物
- 48 紫珀块（≈ 192 合唱果）

这仍是一条有分量的 T2 链，但不再需要 600 次钓鱼结算与 768 个合唱果。
T1 石保持 1 块/次：13 块 1 阶石（首进阶 6 + 1 阶造化 5 + 1 阶灵核 1 +
首 BOSS 门票 1）约 13 钻石 + 13 辰砂 + 52 黑石 + 26 块 0 阶石，量级可接受。

### D5 书页与配方同源

「仪式入门」直接绑定两条完整配方 id：

```json
{ "type": "gensokyou:ritual_page", "ritual": "gensokyou:zaohua_circle",
  "recipe": "gensokyou:zaohua_stone_t1" }
```

- 不再依赖 JEI 才能看到仪式石配方；
- 2 阶页是否挂 `end_unlock` 取决于「是否愿意在书里提前露出紫珀块」；
  建议常驻，因为配方卡本身就是最自然的维度提示。

### D6 飞行：文档向实测让位

实测表明飞行耗灵会让 BOSS 战几乎不可玩，因此当前设计是全阶级 0 耗灵。
本变更只改文档（README + `project.md`），不改代码数值：

- README 删除「阶级越高越省、五阶几乎免费」；
- `project.md` §3.2 的 5%/2%/1%/0.5%/0% 改为「不耗灵」；
- `superhuman-temper` 的「默认全 0」保持不变。

## 已确认的设计取舍

- **玩家神恩等级不门控仪式与召唤**：T0 玩家理论上可以搭 5 阶祭坛；
  这是有意设计，因此召唤配方**不加** `minPlayerTier`。
- **首 BOSS 的书门票保留**：重复打 BOSS 由「镇魂返照」解决，
  不把引导书改成 9 残页。
- **1 阶进阶 `spCost = 200,000`** 保留，不再调整节奏。
- **`material_star_silver` 直接挂 `nether_unlock`**，不新建 advancement。

## Risks / Trade-offs

- [花精之滴多用途] 既是 T2 带信物、又是露米娅召唤料与主题卡料。
  → 信物不消耗，玩家需要至少 2 个（1 个常驻信物、1 个消耗）；书里要写明。
- [黑石/紫珀把 T1/T2 锁到维度] 这是有意的进度门，但玩家可能不带够。
  → 仪式入门页显示配方，配方卡本身就是提示。
- [书页门槛改动会影响已读状态] Patchouli 的 advancement 变更不会回滚已解锁页；
  → 只影响新玩家，老档可接受。
- [T0 可烧高阶门票] 已确认为可接受设计；不做 `minPlayerTier` 硬门。
