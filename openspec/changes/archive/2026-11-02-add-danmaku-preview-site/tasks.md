## 1. 导出器

- [x] 1.1 假 `DecisionProvider`：静止 BOSS 锚点、静止木桩、地面、全区块 loaded。
      场景常量集中一处并注明"改动即全量基准失效"。
      **验收**：常量与 design D10 逐项一致。
- [x] 1.2 注入木桩为合成 `DecisionProvider.Player`；缺玩家时导出器 MUST 报错退出。
      **验收**：临时置空玩家表 → 导出失败并说明原因（证明 `aimed` 组依赖它）。
- [x] 1.3 逐 tick 取投影并按 design 的基准形状编码（成员/样式/预警/帧索引）。
      字段覆盖 `ProgramRenderView.Member` 全集。
      **验收**：投影里非空的字段在 JSON 里 MUST 都有对应项；缺失字段写断言。
- [x] 1.4 确定性编码：固定小数位、成员按稳定 id 排序、无时间戳/路径/locale 依赖。
      **验收**：同一 commit 连跑两次，`fc /b` 逐字节相同。
- [x] 1.5 覆盖面由 `BossProgramCards` 决定，卡数来自注册表而不是手写常量。
      **验收**：注册表与基准文件数不一致时导出失败并指出差异。
- [x] 1.6 `--check`：只比对不写盘，不一致非零退出并逐卡报告。
      **验收**：故意改一张卡的一个参数 → 失败；复原 → 通过。
- [x] 1.7 `--only <owner> <index>`：单卡重导，供日常迭代。
      **验收**：只产出该卡文件，其它文件 mtime 与内容均不变。
- [x] 1.8 输出目录与 `.gitignore` 的边界清楚：**基准入库**，临时产物不入库。
      **验收**：`git status` 在干净重导后无未跟踪文件。
- [x] 1.9 Gradle `JavaExec` 任务，classpath 指向 `sourceSets.test.runtimeClasspath`。
      **验收**：`gradle_task.ps1 exportDanmakuPreview` 可跑；`jar tf` 断言产物中无导出器类。

## 2. 预览站

- [x] 2.1 静态骨架：`preview/index.html` + 原生 ESM + vendored `three.module.js`。
      **验收**：断网状态下打开可运行，且没有任何外部域请求（网络面板核对）。
- [x] 2.2 渲染球弹与星形：真贴图、`alpha`/`brightness`/`sizeMultiplier`/`visualScale`、
      星形按成员年龄摆动。
      **验收**：隐藏相位显示为半透明、RGB 保留，与投影的 `alpha`/`brightness` 一致。
- [x] 2.3 渲染激光：三层加色束 + 端盖 + 旋转法阵，长度取 `beamLength`，粗细取样式视觉半径。
      **验收**：同一样式在两个不同长度成员上，粗细一致、长度按数据。
- [x] 2.4 渲染预警：红束/红点 + 出生时刻之前不画实体弹。
      **验收**：拖到 `birthTick-1` 只有预警，`birthTick` 才有成员。
- [x] 2.5 自由相机 + 四个预设机位（玩家眼位、正俯视、侧视、BOSS 后方）。
      **验收**：四个预设都能用键盘/按钮一键切换并保持画面稳定。
- [x] 2.6 时间轴：拖到任意 tick、变速、循环、卡与 BOSS 选择、木桩标记、地面网格。
      **验收**：拖到第 N tick 的画面 == 该 tick 的投影；20 tick/秒基准。
- [x] 2.7 前端 MUST NOT 出现卡名/图案名判断与任何运动求值。
      **验收**：全仓检索前端源码，无 `big_fairy`/`fan`/`rosette` 等语义分支；
      位置仅来自数据与采样插值。
- [x] 2.8 站点内写明边界：无碰撞判定、静止场景不代表实机难度、不替代观感验收。
      **验收**：README 与界面各有一处说明。
- [x] 2.9 HUD 显示当前 tick 的存活成员数与全卡峰值；时间轴底色画逐 tick 存活曲线
      （由成员首末采样做区间计数得出，不重算任何语义）。
      **验收**：页面内比对「HUD 存活数 == 数据中该 tick 存活成员数」，抽样 4 个 tick 全等。
- [x] 2.10 顶点缓冲按**峰值**分配，且写满时自动扩容：MUST NOT 因容量不足静默丢弃成员。
      （初版按平均弹量估算，山女3 峰值 3414 被截到 2048，衍生弹整批不渲染——用户实测发现。）
      **验收**：山女3 全 tick 扫描 `drawn == live` 且 `顶点数 == drawn × 6`，`grows`/`bad` 均为 0；
      另用小容量实例压 100 顶点，确认扩容后一个不少。
