## Context

当前素材经济全部压在 `ppoint`/`bpoint`（同源于小妖精）上，`memory_fragment`（记忆残页）只用于凑书，`spellcard_star` 无正途来源。所有 mod 配方共用同一把钥匙，且升阶石（T1）配方为「钻石 + 石0」，可无限刷矿量产。

既有可复用基建：
- **资源献祭仪式 ×4 + 钓鱼仪式**：`data/gensokyou/ritual_loot/*.json`，池模型为 `commons + 按工具材质 special + nether/end 条件池`，每次结算产 `20 × 4^阶` 件（`SACRIFICE_BASE_COUNT=20`、`COUNT_MULT=4`、冷却 60s）。
- **条件池机制**：`nether`（台上 ≥3 凋灵骷髅头）、`end`（≥1 龙首）解锁，头颅不消耗。
- **工具/材质**：wood/stone/gold/iron/diamond/netherite 六档，决定 `special` 选取。
- **进化仪式 `zaohua`**：多输入合成/升阶，支持 `minTier`、`match:"max"`。
- **众生典籍**：收容 mob 的图鉴，当前创造限定。

## Goals / Non-Goals

**Goals:**
- 建立幻想乡独有素材目录（T1~T2，20 种），给每个阶级物品族一个「阶级名片」。
- 用「信物 + 条件池」把幻想乡素材的产出做成「前期锁死、后期洪流」，且不改动既有仪器式分级逻辑。
- 让五个资源仪式从可选变必经（素材 + 灵炭链）。
- 素材只能由仪式产出/冶炼，原版路径失效。

**Non-Goals:**
- 金石冶炼 / 丰穰 / 隙间渡三个新仪式（另行变更）。
- 人形使物流系统（另行变更）。
- 残影 BOSS 梯队与其专属神材（另行变更）。
- 结界引爆仪式的神材献祭（另行变更）。
- 幻想乡维度内矿脉/植物/鱼的实际世界生成（后续 refine）。

## Decisions

### D1. 素材三段式：凡材 / 灵材 / 神材
- **凡材**：原版物，做配方「体积」，由仪式 commons 池或原版采集供给。
- **灵材**：本次新增的幻想乡独有材（20 种）+ 既有 `ppoint`/`bpoint`/`memory_fragment`/`spellcard_star`。
- **神材**：BOSS 专属掉落，只进专属装备/符卡与**一次性里程碑仪式**的献祭位（本次不落）。

**规则一·物品唯一性**（只管「造不造新物品」，与配方无关）：原版可获得之物 MUST NOT 另立为重复的 mod 素材；命名不得与原版重名、外形需可辨。竹/樱木/向日葵等原版物作 commons 产出，不立为 mod 材。
- 备选：为每类素材都造同类变体（如「灵竹」「神樱」）——否决，徒增语义噪音。

**规则二·配方构成**（管「配方里放什么」）：凡材 SHALL 可自由作配料（不设上限）；**入口层**（T0 石 / 核心 / 法阵）MUST NOT 强制含幻想乡材，允许以凡材 + 少量 mod 钥匙构成；**mod 独有品**（弹幕武器 / 弹幕核 / 灵力核心 / 众生典籍 / 符卡）SHALL 含 ≥1 件 mod 料；**阶级物品**（T(N) 石 / 装备）SHALL 含对应阶级 mod 材。

### D2. 用条件池而非「解锁阶」
资源仪式当前无「阶级」概念，且 `special` 已按工具材质天然分层。新增第四个条件池 `gensokyou`，与 `nether`/`end` 同构：
- 台上摆放对应**信物**（不消耗）→ 该信物对应的**材料带**进入抽取池。
- 信物分带：**指导书** → 低阶带（T1 材）；**隙间碎片** → 中阶带（T2 材）。
- 产量仍由结构阶 `×4^阶` 决定，故「解锁后」也需继续升级资源仪式才能量产。

> 未采用「按玩家/结构阶逐档解锁材料」的方案：要实现分裂式解锁逻辑，复杂且与既有 `special` 分层重复。信物分带把「解锁」外移成一个可摆放的物品，机制零新增。

### D3. 精炼与灵炭 → 归属金山彦命之仪（不在造化）
```
久久能智（木材仪式）→ 幻想乡木材（神木等）
        └─ 金山彦命之仪（熔炼，后续变更）：木材 → 灵炭
                 └─ 同仪：原矿 + 灵炭 ×1 → 金属（灵炭 1 : 原矿 4）
```
- **精炼与灵炭的产出均归金山彦命之仪**（熔炉替代仪式），**本变更不在造化或任何既有仪式里定义精炼/碳化配方**。
- 本变更只保留：灵炭物品、以及「mod 素材不得有原版熔炼配方」的约束占位。
- 备选：早期曾拟「造化碳化」——否决，客户明确要求归金山彦命。

### D4. 冶炼仪式独占
mod 素材**不提供任何原版熔炼配方**；原版炉子既炼不出也不接受。实现仅为「不添加 vanilla smelting recipe」，零成本。冶炼职责未来由「金石冶炼之仪」承接（另行变更）。
- 备选：原版炉子能炼、仪式更快/双倍——否决，客户明确要「不能让原版能炼」，且独占才让冶炼成为硬卡点。

### D5. 冥河瓶取代三途川之水
仪式的动词是「钓」，必须是实物。三途川主题海产以 `sanzu_flask`（冥河瓶，钓上的漂流物）呈现，可开瓶取冥水，日后可入药水/酿造。
- 备选：保留「水」为物品/流体——否决，钓出瓶子里的河水仍牵强，且流体徒增实现。

### D6. 众生典籍走正途
造化配方 `记忆残页×8 + 符纸×4 + 灵草×4 + 书×1`（minTier 1）。让「记忆」母题与第一条 T1 材料链绑死。移除调试期的「创造限定、无配方」约束。

### D7. P/B 点定位不变
`ppoint`/`bpoint` 仍是合法合成材料（低阶灵力胶水），但不做唯一钥匙；`memory_fragment` 升格为幻想乡知识料（符卡 / 众生典籍 / 符纸）。

### D8. 仪式石与核心配方（草案，数值可调）
| 物品 | 配方 | minTier |
|---|---|---|
| T0 石 | 圆石 ×8 + P点 ×1 → 石0 ×8（原版合成） | — |
| T0 核心 | 石0 ×4（四角）+ P点 ×4（四边）+ 钻石 ×1（心）（原版合成） | — |
| T1 石 | 钻石 ×4 + 石0 ×4 + 辰砂 ×4（造化 match:max） | 0 |
| T2 石 | 石1 ×4 + 灵铁矿 ×4 + 星银矿 ×2 + 潮汐晶 ×1（造化 match:max） | 1 |

> 入口层（T0）以凡材为主、仅含 `ppoint` 钥匙，不强制含幻想乡材——见 D1 规则二。

## Risks / Trade-offs

- [早期灵炭产量过低，冶炼手感卡顿] → 三个配比旋钮全配置化；默认碳化 2:1、冶炼 1:4；实机后调。
- [ `gensokyou` 池让资源仪式价值暴涨，挤占其他内容] → 信物门槛 + 结构阶 `×4^阶` 产能限制，解锁前零产出。
- [唯一性红线与既有已规划物品冲突] → 落地前全量审计已有注册名与占位资产清单。
- [隙间碎片来源属后续变更，本变更会出现「有信物功能但无正途获取」的空窗] → 见 Open Questions。
- [额外 20 种物品的图标/模型占位工作量] → 全部走 `project.md` §5 占位规范，正式美术零引用改动。

## Migration Plan

1. 新增物品注册与占位资产（不触碰既有注册顺序）。
2. 数据层：五仪式 `ritual_loot` 加 `gensokyou` 条目与信物条件；`zaohua` 加碳化/典籍/石配方。
3. 代码层：`RitualLootTable`/`RitualLootLoader`/`ToolSacrificeBehavior` 扩展 `gensokyou` 池。
4. 回滚：移除新增条目即可，既有材料与仪式行为不受影响（纯增量）。

## Open Questions

1. **隙间碎片的来源**：残影梯队属后续变更；本变更是否需要给它一个过渡来源（如创造/调试、或某既有 BOSS 低概率），以免信物空转？
2. **指导书作为信物的判定**：是「背包/台面持有即可」，还是要「已读」状态？是否区分掉落的书与合成的书？
3. **T1/T2 石配方数值**：以上 D8 为草案，是否本轮定死还是留 config？
4. **是否更新 `project.md`**：把「素材唯一性红线」写入 §5 或新增 §，作为全局规则基准。
5. **材料图标/模型占位**：是否统一沿用「海洋之心」占位，还是按品类给不同占位源以便肉眼区分？
6. **结界引爆神材献祭原则**：是否本轮仅在 design 记录原则，留待后续变更落地。
