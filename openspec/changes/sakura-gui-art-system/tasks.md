## 4. 跨面板一致性保障（共用素材与规范，不是共用零件）

> ⚠️ 实测结论（两轮零成本装配实验，`build/guiart/kit_experiment*.py`）：
> **「拆零件复用」对烘焙整图不成立** —— 装饰件必然带原纸底残留，
> 「半结构半装饰」的成分（卡片柔和底色 / 金角括号 / 外框金线）拆开后无处可归。
> 故主线是「每个面板各烘焙一张整图」，一致性靠下列共用件保证。

- [x] 4.1 沉淀材质件 `r2_material.png`（1024² 樱色和纸 + 飘落花瓣 + 淡紫粉光晕）作为
      **全局共用素材件**，后续所有面板的 multi_edit 都用它当 `image_2`
- [x] 4.2 沉淀 prompt 纪律（粗简大形 / 整数倍降采样 / 布局靠参考图锁）到 spec
- [x] 4.3 沉淀收口流程（预乘 alpha → 量化 → 结构擦除 → ASCII 叠加 → 光照统一）到 spec
- [ ] 4.4 沉淀樱色系调色板为**代码常量**（Java 侧单一色源），所有面板取自该组常量
- [ ] 4.5 每个新面板 MUST 与仪式核心 A 版**并排目检**，确认无风格落差
