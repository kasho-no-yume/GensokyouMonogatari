## Why

当前 BOSS 弹幕已经具备几何、编队、速率曲线和同步诊断，但表演仍被拆进单弹行为开关、互斥分支和固定同步参数块。八云蓝残魂的普通多拍、锁轴、启停和转弯需求反复牵动核心，说明缺少可组合的运行模型；应在更多符卡依赖这些接口之前重构。

目标是兑现「低带宽、丰富表现、稳定轨迹、可控性能」：符卡由通用操作组装，特殊图案作为独立扩展；新增图案或路径不再要求修改弹体主循环及通用协议封套。

## What Changes

- **BREAKING**：BOSS 符卡改用类型化 `DanmakuProgram`，显式区分时间组织、逻辑组、坐标帧、图案生成、运动、表现、碰撞和生命周期。Track 保留为作者的视觉分轨，不承担组作用域。
- 引入可组合操作目录：顺序/并行/重复、目标与坐标快照、组与发射计划、平移/转弯/旋转/缩放、成员脱离、派生发射、预警、伤害窗口和归属清理。详细输入、输出、时钟、扩展契约见 `operations.md`。
- 补充常用基础：有界多代分裂事务、移动发射器、球面/螺旋柱、法阵billboard、波形偏移、贝塞尔路径、镜像与错时。`pattern-recipes.md`给出四个用户案例与未来配方；future能力明确不计为本次已支持。
- 增加通俗作者指南及技能操作台账，严格区分planned/implemented/verified/legacy-only，避免把拟定API当成可调用实现。
- **BREAKING**：BOSS 组以共享描述、服务器时间和稀疏权威事件同步，使用独立的数据运行时及批量渲染/碰撞入口，逐弹原版实体不再是新 BOSS 路径的网络载体。已有非 BOSS 弹幕保留实体路径。
- 确定性运动能直接求任意时刻状态；新增路径通过类型注册接入。世界查询只在服务端决策边界执行；实时玩家位置不能被「可预测」当作双方一致的事实。
- 明确组、发射批次与成员身份，以及原子批次准入、整组取消、目标失效、预警匹配、跨轮存活、切卡/死亡清理、断线重追踪和恢复。
- 迁移大妖精 3 卡、山女 4 卡、露米娅/傩面现行 5 卡及其底噪；以 Excel 八云蓝残魂 8 卡替换现行蓝 8 卡。修正已知静默忽略参数与重复子拍问题，差异必须登记。
- 增加组合性、重建、网络和性能验收；先做代表性纵向切片，再迁移全部内容。吸收两项未完成扩展 change 的需求，避免继续扩大旧参数袋。

## Capabilities

### New Capabilities

- `danmaku-program-runtime`: 类型化程序、组合操作、图案扩展、逻辑组、运动求值与生命周期。
- `danmaku-program-sync`: 组级协议、时间映射、权威决策、兴趣管理、迟到与恢复。
- `danmaku-program-migration`: 全量内容映射、非 BOSS 隔离、组合与性能门槛、旧路径退出。

### Modified Capabilities

- `danmaku-track-composition`: 为新程序规定编排替代契约、显式一次性/循环、多轨共享、生命周期和完整批次预算。
- `danmaku-behaviour`: 新程序的类型化行为通道与同步载体，取代单弹开关约束。
- `danmaku-motion`: 新程序的组变换与局部路径组合、共享描述和独立归属。
- `danmaku-leg-motion`: 新程序的异构段、显式段尾策略及可重建方向采样。
- `danmaku-pipeline-capacity`: 新程序的状态准入、权威事件、预算与数据碰撞路径。
- `danmaku-timeline`: 新程序的纯函数数学边界、共享时钟、陈旧时钟处理。

## Impact

- 涉及 `danmaku/track/`、`danmaku/motion/`、`danmaku/render/`、网络注册、BOSS 基类与默认攻击、预览/诊断命令、客户端渲染和碰撞桥接。拟新增 `danmaku/program/`、`danmaku/runtime/`、`danmaku/sync/`。
- 保留并适配已有几何数学、视觉资源、伤害/擦弹公式、激光裁剪规则和测量工具；玩家武器、玩家符卡及普通妖精的实体弹幕不在本次迁移范围。
- 程序以 Java 类型化构建器编写，网络传输有界数据，不引入脚本引擎或外部几何文件。客户端与服务器须具备兼容操作注册表与程序版本。
- `extend-danmaku-orchestration`、`extend-danmaku-shapes` 的交接关系详见 `migration.md`；本提案不删除其文件或当前工作区代码，不把未完成验收记为完成。
- 本 change 包含运行时与内容迁移，分阶段交付；不含新 BOSS、美术重制、通用物理模拟、自动证明所有三维通路或连续自机追踪的零带宽承诺。
