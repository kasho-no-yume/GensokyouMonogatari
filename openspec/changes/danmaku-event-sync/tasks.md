## 4. 行为迁移

- [ ] 4.1 将灵符目标切换和永久丢失迁移到服务端事件；客户端不再独立改变权威目标状态
- [ ] 4.2 依据实验决定灵符使用离散事件、方向关键帧或两者组合，并限制预测窗口
- [ ] 4.3 若激光几何差异达到门槛，实现服务端权威长度/方向关键帧；客户端视觉缓存按序号失效
- [ ] 4.4 若存在实际中途改向/速率变化入口，将其迁移为带完整新运动输入的 `REDIRECT`

- [ ] 4.7 验证客户端事件永远不参与服务端目标选择、命中、伤害、分裂预算和生命周期结算
