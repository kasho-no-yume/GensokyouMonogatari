# Proposal: 人间之里群系全面改造（Rework Human Village）

## Why

当前幻想乡维度的人间之里（`gensokyou:human_village`）仅是一片带半径 72 格平地预留区的空旷草甸，既没有东方原著中代表性的地标建筑，也没有江户町家风貌的普通民居、水系与街巷路网，已实现的客户端环境居民（`add-client-village-residents`）也仅有 8 名样例站位，无法呈现“繁华的人间之里”的生机。

同时，现有的幻想建筑块配色系统（`GLC2`）将染色数据强绑定于绝对世界坐标，无法支撑“1 套民居 Base + 程序变体 × 多朝向旋转 × 运行时调色板”的复用式村庄构建。

## What Changes

1. **升级幻想建筑块体系与染色引擎**：
   - 新增若干和风/町家核心建筑块（木半砖、木楼梯、砖半砖、砖楼梯、和纸障子/格栅窗、可染色暖帘/挂布、可染色书架、木栅栏门、和纸提灯等），同步扩展 `ResidentGround.isPaving()`。
   - 在完全兼容旧世界坐标 `GLC2`（博丽神社与外围地标零改动）的基础上，新增 **局部坐标模板染色格式 `GLC3`** 与 **实例锚点查色层（`origin + rotation + paletteTheme`）**，并新增人间之里道路/广场/水渠的**零内存程序化着色层**。
   - 新增服务端→客户端村庄实例清单同步包 `HumanVillageLayoutSyncPayload`（约 2–3 KB），使随世界种子微调的村庄在客户端正确染色。

2. **改造人间之里地形与水系（`GensokyoLayout` + 水系 Feature）**：
   - 将中心单调平地改造为**微高差台地 + 贯城浅溪**：中心繁华商街台地（`Y = 72`）、村北稗田家名门高台（`Y = 75`）、村南/东南蜿蜒浅溪（河床 `Y = 68..69`，显式填水至 `Y = 70`，石护岸 + 桥梁）、村西缓坡过渡至魔法之森边缘林地；博丽参道在 `X = 40` 自然接入村东外围村道。

3. **确定性核心 + 种子微变外围的村庄排布与密度梯度（`HumanVillagePlanner`）**：
   - **边缘禁建带**：距离 `human_village` 群系边界 `≥ 220` 格内绝对无房屋（且城区外缘收敛在中心半径 `200` 格内，周围留出数百格田野与自然草甸）。
   - **由外向内加密**：外郊农舍带（`160..200` 格，稀疏）→ 中密町家带（`110..160` 格）→ 高密商业核心区（`0..110` 格，紧凑临街）。
   - **核心区锚定 + 外围微变**：4 大功能地标、龙神像中央广场、东西/南北主干道、核心商街坐标固定以完美配合假 NPC 演出；外围民居组团、变体选择、调色板与次级支路随世界种子细微变化。

4. **分层村庄道路与桥梁生成算法（`VillageRoadRouter`）**：
   - 四级路网：主干道（宽 5 格，对接东口与核心地标）→ 次级环巷/水巷（宽 3 格）→ 民居门廊接入支路（带坡度/建筑避让/已有道路复用偏好的正交 A* 寻路，连接绝大多数房屋与全部特殊地标）→ 跨溪自动木拱桥/石桥。
   - 全路网采用 `landmark_*` 铺装，兼顾防熊与假 NPC 脚下白名单。

5. **建筑设计群（由高阶架构/美术侧实现并经实机视觉验收）**：
   - **4 座特殊 NPC 功能地标**：香霖堂（村西林缘）、鲵吞亭（村东南水巷）、铃奈庵（中央商街西南）、稗田阿求居所（村北高台大宅）。
   - **6+ 类非功能装饰地标**：龙神像中央广场、东/西/北村口冠木门与高札场、跨溪朱栏/青石拱桥与水车小屋、4 类市集摊位（团子茶摊/鲜鱼蔬果摊/和伞布匹摊/古书杂货摊）、街角古井/地藏小龛/神木休憩坛。
   - **普通 NPC 民居（1 套参数化町家 Base 派生 10 种结构变体 × 8 套运行时调色板 × 4 朝向）**。

6. **假 NPC 繁华演出编排（`assets/gensokyou/village_residents/human_village.json`）**：
   - 充分利用 128 槽位上限与 96 格渲染视野，编排龙神广场围观聊天、主街往来行人、市集摊贩与顾客、铃奈庵门前读者、鲵吞亭水巷酒客、高札场看告示村民、稗田宅门前巡游等完整动静演出。

## 分工边界

- **高阶模型（本方）负责**：
  1. 完整详实的设计文档（本 OpenSpec 变更包）。
  2. 新增幻想建筑块设计（方块定义、灰度贴图、模型）。
  3. 4 座特殊 NPC 地标、非功能装饰地标、以及 1 套参数化 Base 派生 10 种民居变体的 Python 建筑生成器实现与 `.nbt` + `.local.bin` 导出。
  4. 提供预览图与游戏内实机预览命令，配合用户逐一审视迭代至视觉满意。
- **下游实现模型（照图施工）负责**：
  1. `GLC3` 局部染色读取、`LandmarkBlockColors` 实例锚点/逆旋转/调色板替换/道路程序化着色、`HumanVillageLayoutSyncPayload` 同步。
  2. `GensokyoLayout` 地形微高差台地与河槽改造、`LandmarkClearanceFilter` 更新。
  3. `HumanVillagePlanner`（密度梯度、边缘禁建、碰撞放置、种子微变）与 `VillageRoadRouter`（分层路网、A* 接路、跨溪架桥、浅溪填水）。
  4. `HumanVillageManager`（`SavedData` + 区块加载放置 + 保护区禁放 + 预览/传送调试命令）。
  5. `human_village.json` 128 名假 NPC 正式演出配置与全量单元测试。

## Impact

- 涉及模块：`registry/LandmarkBlocks`、`landmark/*`、`client/LandmarkBlockColors`、`client/resident/ResidentGround`、`network/*`、`worldgen/GensokyoLayout`、`worldgen/LandmarkClearanceFilter`、`worldgen/human_village/*`（新增）、`tools/export_human_village_*.py`（新增）、`assets/gensokyou/village_residents/human_village.json`。
- 向后兼容：博丽神社主模板、博丽外围三地标、样件维度 `GLC2` 配色与现有测试保持 100% 不变。
