## Decisions

### D1 依赖与分阶

依赖前一change的校准关卡、属性单位和真实消费。T1对应玩家1～2阶、T2对应3～4阶、T3对应5阶，但核阶范围与玩家阶最终边界是不同概念。同一低阶核在高阶不自动升级；高阶核借给低阶的合法装配路径也必须测试，不私加玩家阶装备门。

### D2 单池与单位

采用同一受控定义表：ID、域、单位、核阶数值带、类型权重、数值分布、预算参数、消费能力。首次与洗练共用生成核，只注入不同洗练度。概率用百分点/绝对比例贡献，不再统一取已有标准值的零头；护壁按绝对指数预算；灵力强度为固定参考阶派生的绝对值，再受实际玩家阶额度约束。射程等杂项保留有限区间。

T1/T2/T3每枚分别3/4/5条，ID唯一。首次池大小必须足够；定义错误显式失败，不静默少给或复制ID。

### D3 有界随机与组合预算

先按权重抽取唯一类型，再在各自区间做低位密集抽样并验证组合。候选q=u^k可用，但精确参数由校准报告决定。上限不代表常见结果，不保证主条；多高条组合具有非零概率，不强制只有一条高值。

组合判据复用前一change的输出、资源、生存预算，至少覆盖该核适用的两个玩家阶、低/中/高天赋和多种弹幕核/卡组；运行时不根据实际DPS对整核打折。拒绝采样须有有限尝试上限与确定性合法回退；回退不补一条极品，不少给条数，不循环卡住服务端。统计验证拒绝过程后的实际分布，而非只报告原始u分布。预算是天花板，不把每枚核归一成等强。

不复用旧“总DPS≤+80%”作为新目标。新边界需由前置校准给出；未来其他来源可调整核投放表，不把单核范围与全局上限绑定成同一常量。

### D4 软保底

保留时计数+1，采纳时向下取整减半。洗练度只改善有界分布，不平移法定上沿、不越组合预算、不保证类型或极品。类型权重不因洗练度暗改。暂存-提交、会话绑定、物品快照复验与全量保留保持原契约。

### D5 槽数与学习分离

槽数clamp(tier,0,5)，服务端、HUD、按键统一。保留按住修饰键+数字键交互。只改容量；已学、冷却、灵力不足校验保留，空槽不自动授予卡。为了避免本次无意放宽旧学习数量，旧正式学习资格独立保留为遗留策略，不能再读取新槽数计算学习上限；后续符卡change移除旧限制并按幻想乡进度开放学习。后续方向明确为学习总数不限、一二阶固定卡、三阶后自由配装，本次不实现该流程。

原有卡不因扩容被删除、复制或自动重新配装；新增槽默认空。测试换槽不会重置既有冷却；若发现原有漏洞则记录必要修复，不把槽扩容当作冷却豁免。

## Risks / Trade-offs

- [一枚核承担过多属性] → 允许普通结果与低效杂条，但统计流派可用组合概率，不能以“理论可能”代替可刷到。
- [拒绝采样消灭惊喜] → 校验单项顶格和多高条合法样例仍可产生；记录稀有率与预算拒绝率。
- [只开槽早期无卡] → 明示只做容量，早期固定卡不虚构；已授予的卡正常服务端校验。
- [旧神核超生成预算] → 原始成果保留，显式legacy范围；新预算保证仅适用于新版生成，旧档风险另外报告。
